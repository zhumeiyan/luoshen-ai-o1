# 萃取论 - 面向全球适用的双向共识人机交互框架

> **不是单向指令，也不是黑箱输出。**  
> 而是一套**天然适配多元文化**的协作机制——让不同国家、不同语言习惯的用户，都能与AI在平等对话中形成可追溯的**共同理解**。

---

## 核心逻辑（30秒看懂这套框架的普适性）

传统人机交互往往隐含了特定文化或语言的行为预设，导致在不同国家使用时需要反复适配。**萃取论**从头设计了一套**不依赖任何文化先验**的双向共识流程，确保无论用户来自哪里，交互逻辑保持一致且可调适。

1. **意图萃取（Intent Extraction）**  
   不假定用户的“标准表达”，而是通过多轮澄清和情境锚定，将任何语言下的模糊需求**拆解为客观的认知单元**（而非直接映射到固定指令）。这套拆解规则本身是可配置的，能适应不同语言的表达习惯。

2. **规则协商（Rule Negotiation）**  
   系统主动展示自身推理的**假设边界和不确定区域**，并邀请用户对关键节点做出确认。这一过程不预设谁必须听谁，而是让双方在彼此的逻辑框架中寻找最大公约数——这种“协商式”设计天然适应不同国家用户的决策风格。

3. **共识沉淀（Consensus Precipitation）**  
   每次交互的输出是一份**带有分歧标注的共识记录**，明确哪些点已对齐、哪些尚待澄清。这份记录独立于具体语言和文化，因此后续在不同国家场景下复用或修正时，都能保持透明的可追溯性。

这套框架不依赖固定模板，可根据任务复杂度和用户偏好动态调整对话深度，因此从日常助手到跨国企业决策，都能提供一致的、高适配性的人机协作体验。
