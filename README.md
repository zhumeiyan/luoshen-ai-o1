## 核心公理（不可改动）

```
E = E + dE
P' = F + f(E)   其中 f(E) = E + 底噪(0.01)
F' = P + g(E)   其中 g(E) = -E + 底噪(0.01)
```

环境层可修改（W矩阵/G电导、R网、感官注入、SCALE、S_DECAY），底层LOOP固定。

## 关键新增：莱文生物电网络环境层（01_environment/）
