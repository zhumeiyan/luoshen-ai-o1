## 四、任务

读这份文件，逐条判断：

对每一条（50条 + 待落10条），做四件事：

1. 落哪层？
   锚点 / 引擎 / 角色链 / 反哺 / 索引 / 技能 / 内部哨兵 / 回检 / 透明痕 / 其他

2. 现在能不能落？
   能落 / 不能落 / 待定

3. 碰不碰硬锚点？
   碰了就不落

4. 跟现有哪块冲突？
   推演者 / 反哺 / 存在确认 / 内部哨兵，有没有重叠或矛盾

输出：
  表格：编号 | 落层 | 能落？ | 碰硬锚点？ | 冲突？
  汇总：能落的几条、不能落的几条、碰锚点的几条、有冲突的几条

纪律：
  只判断，不拍板
  不落地的，说清原因
  有冲突的，说清怎么解
  算不出来就说算不出来
  标 [判读]
