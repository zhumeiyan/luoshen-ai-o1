# 设备规格采集标准 v0.1.1

## 一、总则

洛神赋感官矩阵的采集标准，约束：
- 数据从哪来（物理来源）
- 什么量级（数值范围）
- 怎么存（矩阵 + 入痕）
- 原始量和导出量的关系

纪律：
- 不做语义解释/意义推断
- 只做"物理量 → 矩阵 → 入痕"
- 原始量和导出量都存，来源和关系必须标清

## 二、原始量原则

### 定义

物理传感器输出两类数值：

| 类别 | 标记 | 含义 | 例子 |
|---|---|---|---|
| **原始量** | [事实·原始] | 传感器直接测得的物理量，未经过设备固件转换 | ADC 计数值、光子计数、多普勒频移 |
| **设备输出级** | [事实·设备输出级] | 设备固件/算法处理后输出的导出量 | 温度（℃）、速度（m/s）、声压级（dB SPL） |

### 规则

1. **两个都存**：如果设备同时输出原始量和导出量，必须同时写入矩阵
2. **标清关系**：payload 里必须注明哪个是原始量、哪个是导出量、两者之间的换算链路
3. **不混用**：同一个矩阵子模态只存一种，不把原始和导出混在一个子模态里
4. **来源必载**：每条 payload 记 `来源` 字段，指明设备型号或标定参考

### 典型关系

| 感官 | 原始量 | 导出量 | 换算 |
|---|---|---|---|
| 红外热成像 | 辐射计数（counts） | 温度（℃） | Planck 函数 + 发射率校准 |
| 雷达 | 多普勒频移（Hz） | 速度（m/s） | v = λ·Δf / 2 |
| 听觉 | 声压（Pa） | 声压级（dB SPL） | dB = 20·log₁₀(p/p₀) |
| 视觉 | 光子计数（ADU） | 亮度（cd/m²） | 量子效率 + 伽马校正 |

## 三、矩阵通用结构

每个感官矩阵必须包含：

### 3.1 十一字段（to_summary() 键集）

| 字段 | 说明 |
|---|---|
| 感官 | 感官通道英文名称（如 视觉 / 听觉） |
| 子模态 | 该矩阵对应的子模态名 |
| 尺寸 | 行×列 |
| 尺寸说明 | 行是什么、列是什么 |
| 取值范围 | 矩阵值的物理量程 + 单位 |
| 分辨率 | 最小可辨变化量 |
| 采样频率 | Hz（如果是连续采样） |
| 部位 | 测量位置或视野 |
| 来源 | 设备型号或标定参考 |
| 时间戳 | ISO 8601 毫秒精度 |
| 状态 | [事实·终版] / [判读·待核] |

### 3.2 入痕规范

- 矩阵入痕走 `Trace.append`，hash 为 `rec["hash"][:12]`（sha256 截取前 12 hex）
- 不用 blake2b、md5 等其他哈希算法
- 全部矩阵统一

### 3.3 校验矩阵

每个矩阵模块提供 `self_check()`：
- 字段对齐（11 字段，与视/听/触/温/痛/发声/神经元一致）
- 尺寸对齐（符合 SPEC 声明）
- 哈希链完整性
- 运行入口函数是否能跑通

## 四、新增感官矩阵 checklist

```markdown
- [ ] SPEC：感官名 / 子模态列表 / 物理量程 / 分辨率 / 采样频率 / 部位 / 状态
- [ ] RESOLUTION：分子模态，不混存
- [ ] frame_to_*：按子模态拆 factory，不用 if-then 分支
- [ ] Matrix 类：to_dict() / to_summary() / from_frame()
- [ ] capture_*()：封装 frame → matrix → 入痕全流程
- [ ] build_test_frame(pattern=...)：合成测试帧
- [ ] self_check()：四项校验
- [ ] 十一个字段与现有七矩阵一致
```
