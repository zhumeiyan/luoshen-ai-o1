## 五、物理约束（门控）

```
if 总激活 > 当前上限:
    门控激活 = 激活 × (当前上限/总激活)
else:
    门控激活 = 原值

热量 = Σ(门控激活²)
功耗饱和度 = 活跃节点(|激活|>0.1) / 功耗满值
温度饱和度 = 热量 / 温度满值
内存饱和度 = len(筋树) / (节点数×(节点数-1))
压力 = max(内存, 温度, 功耗)
目标上限 = max(0.01, 上限满值×(1-压力))
当前上限 = 0.9×旧 + 0.1×目标上限
```

## 六、出筋规则（三元严格）

```
同拍亮才连：|Δ激活| > 阈值 + 同拍出现
第一拍跳过
脑内节点对 → 概率0.15
跨脑节点对 → 双端>0.02 + 概率0.05
已存在的筋 → 更新末传时刻 + 0.05概率长位点(疲劳>0.5)
筋位点上限 40
```

## 七、代谢规则

- 疲劳衰减：每传导一次 ×0.0
- 传导次数 % 200 == 0 且随机<0.5 → 不再衰减（延迟分散）
- 死筋：末传>5000 且每 1000 拍扣 1 位点，<1 删除
- 疲劳恢复：每 100 拍 → 疲劳向 1.0 回升 (100/300)×(1-疲劳)
