# 全上融合架构 v0.2

## 一、总则

洛神赋多模态融合的核心原则：
- **全上**：所有通道全部接入，不丢弃任何通道
- **自净**：每路进融合前先净（去基线、转调制度、标覆盖度）
- **对齐**：时间基对齐，不同频率的通道挂同一时间戳
- **融合规则**：可靠性加权 + 硬门槛否决 + 词典短路 + 相关证据组

## 二、通道定义

### 2.1 九类感官通道

| 通道 | 子模态 | 物理量 | 采样率 | 角色 |
|---|---|---|---|---|
| 视觉 | 亮度 | cd/m² | 30-96 Hz | 主证据路 |
| 听觉 | 声压 | dB SPL | 44.1-192 kHz | 主证据路 |
| 触觉 | 压力 | kPa | 1-10 kHz | 稀疏路（标覆盖度） |
| 温度觉 | 温度 | °C | 1-10 Hz | 自净路（去基线后进） |
| 痛觉 | 刺激强度 | °C/kPa/mA | 事件触发 | 调制路（非证据） |
| 发声 | 基频/声压 | Hz/dB | 44.1-192 kHz | 主证据路 |
| 红外 | 热辐射 | °C/counts | 9-30 Hz | 主证据路 |
| 雷达 | 速度/频移 | m/s/Hz | 10-100 Hz | 稀疏路（标覆盖度） |
| LiDAR | 距离/ToF | m/ps | 10-30 Hz | 稀疏路（标覆盖度） |
| 神经元 | 放电/传导 | Hz/m/s | <1 kHz | 垫底层（非主证据） |

### 2.2 角色定义

**主证据路**：直接参与融合决策，加权投票。
**调制路**（痛觉）：不直接参与投票，但调制其他通道的权重（如高温→降低触觉可靠性）。
**垫底层**（神经元）：提供节律/整合窗口上下文，不单独贡献证据。
**稀疏路**（雷达/LiDAR/触觉）：有效值覆盖度 < 100%，缺席区不填零。
**自净路**（温度觉）：去环境基线后再进融合。

## 三、自净规则

### 3.1 温度觉自净

环境基线约 300 K（室温），叠加信号通常在 1–10 K 范围内变化。
自净：`T_signal = T_raw - T_baseline`
其中 `T_baseline` 取最近 N 秒的中值（环境缓变跟踪）。
**净后**：温度信号反映"与环境偏差"而非绝对温度。

### 3.2 痛觉转调制路

痛觉不直接提供"是什么"的证据，只指示"刺激强度/危险等级"。
调制规则：
- 痛觉强度 > 阈值 → 降低所有触觉通道权重（伤害性刺激不可信）
- 痛觉激活 → 提升温度觉权重（共源线索）
- 痛觉缺失 → 不影响其他通道

### 3.3 神经元垫底层

神经元信号不直接参与投票。
用途：
- 提供振荡相位（theta/gamma 时间窗）→ 时间对齐基准
- 提供整合窗口长度（AMPA/NMDA 时间常数）→ 融合时间常数
- 传导速度 → 不同脑区信号的时间差校准

### 3.4 稀疏路标覆盖度

雷达/LiDAR/触觉的覆盖度：
- coverage = 非零像素 / 总像素
- 覆盖率 < 阈值的帧标记"缺席"
- 缺席帧不参与融合投票
- 不填零（零 = 无数据 ≠ 零值物理意义）

### 3.5 词典路转离散编码

词典匹配（词库/规则）：
- 输出格式：命中 / 未命中 + 候选集
- 命中的直接出结论（短路）
- 未命中的出候选集供其他路投票
- 不做连续值（避免与连续通道混叠）

## 四、归一化：L2 替代 L∞

### 4.1 L∞ 的问题

L∞ 归一化（除以 max(|x|)）：
- 仅保留最大值维度，其他维度坍缩
- 不同通道归一化后分布形状相同 → 完全不可区分
- 实测：换物理值域后 γ 完全不变（量程差被吃）

### 4.2 L2 的方案

L2 归一化（除以 ||x||₂）：
- 保留方向信息，两维均有值
- 不同分布形状在 L2 球面上位置不同
- 相似度用方向差而非幅度差

公式：
```
feat_normalized = feat / sqrt(sum(feat[i]^2))
```

### 4.3 对 Pair/Difference 的影响

- 中心化后 antisymmetric 仍然成立（L2 归一ized 后做 center 运算）
- γ = |g| / σ：g 现为 2D 向量（两维均有值）
- 相似度分布在单位圆上，可用角度距离表征

## 五、时间基对齐

### 5.1 问题

不同通道采样率差异巨大：
- 音频：48 kHz
- 触觉：10 kHz
- 视觉/红外/雷达/LiDAR：10-96 Hz
- 神经元：<1 kHz

### 5.2 对齐策略

**重采样对齐**：统一基准频率（如 30 Hz）
- 高频通道降采样到 30 Hz（取中值/均值）
- 低频通道保持原频
- 时间戳对准到基准网格

**事件对齐**（稀疏路）：
- 雷达/LiDAR 帧对准最近的基准时刻
- 超出时间窗的标记缺席
- 稀疏路不做插值

**缺席标记**：
- 某路在当前帧无数据 → `absent = True`
- 缺席路不参与当前帧融合
- 可靠性置 0

## 六、融合规则五条

### 规则 1：每路相似度转秩/分位再出门

原始 γ 值通道间不可比（不同分布基线不同）。
出路：将 γ 转为秩（0..N-1）或分位（0..1）。
融合时用秩/分位而非绝对 γ 值。

### 规则 2：逐帧可靠性权重 w

每路每帧有可靠性：
```
w = base_reliability × coverage × freshness × pain_modulation
```
- base_reliability：设备固有可信度
- coverage：稀疏路覆盖率（主证据路 = 1）
- freshness：时间衰减（离当前帧越远越小）
- pain_modulation：痛觉调制因子（0..1）

### 规则 3：硬门槛否决（仅对在场且可靠性达标的路）

某路要参与投票必须同时满足：
- coverage ≥ 阈值（稀疏路）
- w ≥ 阈值（可靠性）
- absent = False

不满足的路直接否决（不参与当前帧决策）。

### 规则 4：词典短路

离散词典命中直接定案，不走连续值投票：
- 命中的通道结论优先级最高
- 未命中→连续通道投票
- 冲突（多词命中不同结论）→ 候选集输出

### 规则 5：相关证据组（同源路先并组）

同源通道先并组再参与融合：
- 视觉（亮度+波长）→ 视觉组
- 听觉 + 发声 → 声音组
- 雷达 + LiDAR → 距离组
- 温度觉 + 红外 → 热组

组内采取"或/与"规则，组间投票。
