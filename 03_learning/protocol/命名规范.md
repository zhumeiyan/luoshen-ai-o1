# 命名规范

一、代码关键字：英文（Python 必须）

二、概念名：中文
   痕、锚点、反哺、灰度、果因、环境场、定格
   
三、画面名：中文
   水、坍缩、AI味、鱼能上岸、回声、倒影

四、字段值：中文
   心跳、摄像头、声音、屏幕、会话反思、自检

五、字段名：英文
   task_state、ts、type、trigger、seq、hash、prev

六、测试名：符号保留 + 描述中文
   符号不改（会断代码引用），描述用中文
   例：task_state_默认空、heartbeat_一次、路由_已加载

七、文件名：中文优先

八、文档标题：中文

九、外部对接字段：英文 + 中文注释
