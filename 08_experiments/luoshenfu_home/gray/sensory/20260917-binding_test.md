## 设计

5 个山变体（thin / wide / double / left / low），每山有配对图+配对音。

留出法：每次留出一个山，其余放入记忆。给留出图的图，在记忆中找最像的图，取其配对音作为预判。预判音 vs 留出山实际音 → γ。

反向：给音，预判图。

γ 含义：此处 γ 是【预判 vs 实际】的同模态差异（音-音 或 图-图）。γ 低 = 预判准。

## 三件事回答

### 1. 预判的 γ

正向（图→音）预判 γ 范围：0.0244 ~ 0.0356
反向（音→图）预判 γ 范围：0.0227 ~ 0.1128

大多数低于 0.04。预判 vs 实际同模态差异小 → 预判准。

### 2. 积累几次后，γ 有没有降

无一致趋势。

正向案例：
- double: N=1 γ=0.0326 → N=4 γ=0.0285（降了，因为 left 的音比 thin 的音更接近 double 的音）
- left: 全程 γ=0.0327（thin 在左图空间最近，thin 的音已是最接近 left 的音，增 memory 无用）
- wide: N=1 γ=0.0356 → N=2 γ=0.0311（降了），但 N=4 γ=0.0321（微升）

γ 是否下降取决于新增的 memory 是否包含【在音空间更接近留出山】的配对。记忆数量不是直接原因，记忆的"质量"才是。

### 3. 有没有新东西

无。

机制就是最近邻查找，没有涌现。没有因为 N 增大而出现新的结构、新的交互、新的不可约性质。

但有一个值得标注的事实：
- 正向近邻（图-图近）往往导致低音-音 γ → 图空间的近邻 ≈ 音空间的近邻
- 山的视觉特征（L2 六维）在变体之间保留了与音频特征一致的距离结构
- 这意味着 6D 特征在跨模态之间保留了拓扑：相似的图配对相似的音

这个拓扑保持是绑定的基础，但它是静态的，不随积累而增强。

- 时间衰减：旧记忆权重下降
