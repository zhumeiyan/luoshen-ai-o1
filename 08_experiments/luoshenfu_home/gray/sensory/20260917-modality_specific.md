## 测什么

- 视觉：用视觉自己的特征（廓线、质心、散布、边缘、对称），不套 6D
- 听觉：用听觉自己的特征（频谱廓线、时间廓线、频谱重心、谐波比），不套 6D
- 比：专有 vs 通用 6D，区分度、同一座山两路形状差、有没有新东西

特征维度：视觉专有 23D，听觉专有 23D，通用 6D。

## TEST A：同一座山，视觉 vs 听觉，形状差多少

```
专有特征 L2 距离: 0.833010
通用 6D L2 距离:  0.746545
```

两路都用专有特征 → 0.833 > 两路都用 6D → 0.747。

专有特征下跨模态差异略高：因为廓线结构（垂直廓线 vs 频谱廓线）保留了各自空间信息，没有压平到同一组统计矩。

## TEST B：同一模态，不同东西，能否分开

### 视觉

距离矩阵（专有 vs 通用 6D）：

```
专有:
           thin   wide   double  文字山  文字你好
thin       —      0.382  0.755   0.945   0.912
wide       0.382  —      0.412   0.876   0.755
double     0.755  0.412  —       0.903   0.693
文字山     0.945  0.876  0.903   —       0.478
文字你好   0.912  0.755  0.693   0.478   —

通用 6D:
           thin   wide   double  文字山  文字你好
thin       —      0.228  0.038   0.457   0.585
wide       0.228  —      0.209   0.251   0.374
double     0.038  0.209  —       0.434   0.563
文字山     0.457  0.251  0.434   —       0.135
文字你好   0.585  0.374  0.563   0.135   —
```

**关键：6D 中 山thin vs 山double = 0.038 — 几乎完全 identical。**

视觉 thin = 单尖峰，视觉 double = 双尖峰。这两个东西看一眼就知道不一样。但 6D 把它们压成几乎同一组数。

专有特征：thin vs double = 0.755。正确分开。

垂直廓线对比：
```
山thin:   [50, 50, 1125, 1125, 1125, 200, 200, 200]  ← 中峰结构
文字图:   [4116, 4116, 4116, 4116, 4116, 4116, 4116, 4116]  ← 均匀
```

用 6D 均值 ≈ 509 vs 4116，分得开。但 thin vs 双峰，均值接近 → 分不开。

### 听觉

```
专有:
           thin   wide   double  文字山  文字你好
thin       —      0.031  0.025   0.497   0.552

通用 6D:
           thin   wide   double  文字山  文字你好
thin       —      0.011  0.007   0.599   0.467
```

听觉三座山之间距离小（0.02-0.03），因为频带结构类似。但文字音距离大（0.5左右），说明专有特征把"真山音"和"文字音"的清浊分得很开。

## TEST E：区分度比（类间 / 类内 距离比）

```
视觉 thin vs wide (类内):
    专有:  0.382
    通用:  0.228
视觉 thin vs 文字 (类间):
    专有:  0.945
    通用:  0.457
区分度比:
    专有:  2.47
    通用:  2.00

听觉 thin vs wide (类内):
    专有:  0.031
    通用:  0.011
听觉 thin vs 文字 (类间):
    专有:  0.497
    通用:  0.599
区分度比:
    专有:  16.27
    通用:  54.65
```

听觉 6D 区分度比看起来"更好"(54.6 > 16.3)，但实际上是因为类内距离过小(0.01)——三座真山被压成几乎一样的形状。这不是"更好区分"，而是"压得太扁"。

真正重要的是：专有特征把 intra-class 的结构差异保留下来（thin ≠ wide ≠ double），而 6D 把这些差异压没了。

---

## 三件事回答

### 1. 每个模态用自己的特征，区分度有没有变好

视觉：专有特征区分度比 2.47 > 通用 2.00。更重要的是：6D 完全分不开 thin 和 double（0.038），专有可以（0.755）。这是从"不可区分"到"可区分"的质变。

听觉：6D 区分度比更高(54.6)，但代价是三类真山全被压到 0.007~0.011 的距离——听觉内部变体被消灭了。专有特征保留了三类真山的可区分距离(0.022~0.031)，同时仍然与文字音拉开(0.5左右)。

### 2. 同一个东西，两路形状差多少

专有特征：0.833
通用 6D：0.747

相近。跨模态差异主要由模态本身（视觉 vs 听觉）决定，不强烈依赖特征选择。

### 3. 有没有新东西

有。

**6D 压掉了 thin 和 double 的视觉差异（距离 0.038），专有特征恢复了它（距离 0.755）。**

这直接回答了"所有模态被压成同一套六维特征 → 不同的东西压出来形状差不多 → 分不开 → 积累无用"的假设：

> 6D 不仅是"分不开"，而是**把本质上不同的东西错误地压成几乎相同**。单尖峰和双尖峰的图，在 6D 中几乎 identical；但在视觉专有特征（垂直廓线、质心、散布）中差异巨大。

这意味着：绑定测试中积累的"记忆"如果用 6D 表达，thin 和 double 会被当成同一个东西，记忆无法区分它们。如果用专有特征，thin 和 double 在记忆中各占不同位置。
