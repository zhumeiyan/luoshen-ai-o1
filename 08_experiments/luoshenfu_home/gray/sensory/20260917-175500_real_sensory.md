## 输入

### 视觉（山的图）
8×64 亮度矩阵，单位 cd/m²
- row 0-1：天空（30-70 cd/m²）
- row 2-4：山峰轮廓（三角形，山顶 ~5000 cd/m²）
- row 5-7：地面（150-250 cd/m²）

像素条带示意：
```
row 0 (天空): ................................
row 1 (天空): ................................
row 2 (山底): ++++#########+++++++++++++++++++
row 3 (山腰): ++++++++++++++++================+
row 4 (山顶): .+++#########+++................
row 5 (地面): ++.++.+..+..+..+................
row 6 (地面): ++.++++....+..++................
row 7 (地面): ++...++..++.+.+................
```

### 听觉（人声"山"）
8×64 声压矩阵，按频段分层（模拟频谱图）
- row 0: 低频 <100Hz（元音 a 能量）
- row 1-3: 中低频 100-500Hz（元音谐波）
- row 4-6: 中高频 500-2000Hz（辅音 sh 擦音）
- row 7: 高频 >2000Hz（擦音噪声）

时间轴：起始 col 0-8（辅音 sh 噪声）→ 中段 col 8-48（元音 a 周期波）→ 收尾 col 48-64（鼻音 n 衰减）
