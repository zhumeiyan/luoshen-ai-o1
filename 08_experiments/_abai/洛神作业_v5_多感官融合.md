  L234-252: 激活累积(情绪色价/饥饿/噪声/感受器都加在这)
  L274-276: 门控缩放(EMA)

你应该已经知道(v1 已经学过):
  光通道:差分变换,恒常光感知不到
  声通道:差分变换 + 心跳节律搭载
  力通道:直接感知,恒常力可感知
  温通道:max(0,...)裁剪,<288K 一律归零
  回接通道:自身激活差反馈

这份作业的关键洞察:
  "同一个物理事件"会同时打到多个通道。
  例如:光从 50 跳到 550 →
    光通道:立刻感知到(差分变大,超过槛 0.015)
    声通道:不变(光不影响声)
    温通道:不变(纯光不升温)
    但"灯开了"这件事,人类会同时感知到光+声(电流嗡鸣)+温(灯丝发热)。
    洛神能不能把"多个通道同时变化"融合成"一个事件"?

题目 1: 列出引擎里"同一底层物理事件打到至少两个通道"的全部场景
---------------------------------------------------------------------

已知场景(你要验证):
  场景 1.1:心跳节律
    声通道:L172 `声值 = 45 + 3.0*sin(2π·tick/10)`
    同时影响:
      - 声通道末梢差分输出(你 v1 作业算过,±0.044)
      - 叠加在声值上的心跳频率,能被下游激活节律检测到
    这里只有一个通道(声),算单通道。

  场景 1.2:环境温从 287K 涨到 297K(跨温裁剪槛 288K)
    温通道:L176 `max(0, min(1, (温-288)/15))`
    287K → 输出 0(裁剪),297K → 输出 0.6
    同时影响:
      - 温通道感受器(单通道)
      - 温通道热量(L268 热量 = Σ激活²,温贡献影响门控压力)
    但这是同一通道内部级联,不算"多通道"。

  场景 1.3:喂(round_num % 3 == 0 且存货 ≥ 4)
    L385-389:饥饿下降 + 存货下降 + 激活节律变化
    同时影响:
      - 饥饿驱动(L244 `0.6*tanh(hunger/8)` 立即变化)
      - 情绪色价(term1 饥饿分数立即变化)
      - 情绪色价(term4 能量供给率,存货下降)
    这是你 v3/v4 情绪公式已经捕捉到的耦合。

你要找的是"还没有被建模的场景"——
  一个物理事件同时引起光/声/力/温 ≥ 2 个通道同时变化。

形式化判据:
  事件 E 在 tick T 发生,
  通道 A 在 tick T+Δt₁ 产生显著变化(|变化|> 槛的 10%)
  通道 B 在 tick T+Δt₂ 产生显著变化(|变化|> 槛的 10%)
  Δt₁ 和 Δt₂ 都能在 ≤ 5 tick 内对齐
  → 这算一个"跨通道事件"

  Q1 提交物:每个场景一张卡片,写清:
    - 事件 E 是什么()
    - 同时打到哪些通道
    - 每个通道延迟 Δt₁,Δt₂ = ? tick (用代码行号+公式推)
    - 在你的"融合感知"里,能比单通道早几个 tick 发现 E?

评分标准(猫爪判卷 v5 会逐条对照)
---------------------------------------------------------------------

[P1] 场景找全了吗?
  引擎里已知的跨通道事件,猫爪已经藏了 3 个在代码里等你挖。
  找全 3 个 = 80%,找全 + 自验数据 = 100%

[P2] 时间对齐实验 Δt 实测值与你 v1 推演出来的理論值一致吗?
  误差 ≤ 1 tick = 100%
  误差 2-3 tick = 接受(因为有 jit/computation 抖动)
  误差 > 5 tick = 你错了(或者你的理论推错了,看 v1)

[P3] 融合方案能不能跑?
  在引擎里实际加融合感知行号,给出"融合后比单通道快几个 tick"的实测值
  跑不出 = 0 分
  跑出来和预测偏差 > 50% = 重做
