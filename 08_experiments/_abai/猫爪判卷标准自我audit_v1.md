第 1 节:3 条预测失败的形式化归因
---------------------------------------------------------------------

[预测 1 失败] 非单调性(55.4% 上升步) + 存货=0 阈值 0.366 > 0.35
  数学本质:公式 z = -0.5·饥饿分数 - 0.3·激活同步度 - 1.0·筋树压力 + 0.8·能量供给率
           其中"饥饿分数"和"筋树压力"受同一个底层变量(饥饿驱动的总激活)影响。
           饥饿↑ → 饥饿分数↑ → term1 更负 → z 更负 → 情绪↓  (想让它降)
           饥饿↑ → 总激活↑ → 功耗饱和度↑ → 筋树压力↑ → term3 更负 → z 更负 → 情绪↓  (也是降)
           两个 term 同向,应该是单调递减才对。
  实测为什么非单调?
           因为"压力"是 max(内存, 温度, 功耗),在 feed 间歇期:
             tick N(刚喂完):hunger 恢复到低 → 激活低 → 温度/功耗饱和度低 → 压力↓
             tick N+3000(饥饿上升中):hunger↑ → 激活↑ → 温度/功耗饱和度↑ → 压力↑
           在相邻两次 feed 之间,压力从低→高,而 term1 的饥饿分数也同向变化。
           但压力透过门控(L274-275)有一个 ~10 tick 的指数滑动延迟;
           饥饿分数是即时计算(没有延迟)。
           一个快变量 + 一个慢变量 + 两个负号 = 在 feed 节拍上产生振荡。
           预测没有建模这个"双时间尺度耦合"。

[预测 2 失败] 信号量级不足(0.0036 vs 0.04,差 11 倍)
  数学本质:注入量 = (情绪色价 - 0.5) × 0.1
           情绪色价 ∈ (0.35, 0.63) 由 trace 实测
           → (情绪 - 0.5) ∈ (-0.15, +0.13)
           → 注入量 ∈ (-0.015, +0.013) 峰值约 ±0.015
           而回接_base = ΣΔ激活 / 20.0,典型幅度 ±0.025(见 trace)
           信噪比 ≈ 0.015/0.025 = 0.6 (情绪信号没有主导权)
  量级预测缺失:洛神在 v3 写注入系数 0.1 时,没有代入情绪的实测范围做信噪比预估。
              "0.1"这个值在我判卷时也没有验算量级。

[预测 3 失败] 相关性符号反(+0.985 不是 -0.4~-0.1)
  数学本质:洛神的推理链 ——
            情绪色价低 → hunger/存货低 → 筋树压力高 → 门控上限低 → 负相关
  实测为什么反了?
            情绪色价低 → hunger 高 → 激活驱动(0.6×tanh(h/8))强 → 节点更亮
                       → 温度/功耗饱和度上升 → 筋树压力高 → 门控上限低
            同时情绪色价低本身也来自 hunger 高(term1 主导)
            ∴ 情绪色价低 + 当前上限低 都被同一个"hunger 高"驱动 → 正相关
  洛神错把"情绪低 ↔ 饥饿高 ↔ 门控上限低"的三方共变判成了因果链。
  实际上是 hunger 作为共同原因同时驱动两个末端变量。

第 2 节:猫爪判卷 v3 的裁定盲区(自我审计核心)
---------------------------------------------------------------------

盲区 1:只检形式,不检量级
  裁定词在判卷 v3 第 2 节:"注入信号量级 ±0.05,与回接差/20 的典型值 ±0.05 同阶"
  这句话在数学上错了——情绪信号不是 ±0.05,是 ±0.015(因为情绪范围 0.35~0.63)。
  判卷时没有:"情绪 - 0.5" ≈ ? → 先估个范围 → 乘以 0.1 → 再比回接典型值
  判卷卷面里的量级判断是直接抄了洛神的 ±0.05,没有亲手算过。

盲区 2:只检静态,不检动态
  裁定词:"3 条预测全部可证伪" ← 这个判定只看洛神写了可证伪条件。
  实际该做的:把 z 公式里的四个分量各自求范围,代入存货=20→0 的极端场景,
              看情绪的理论上下界在哪,洛神的阈值(0.35)是不是在边界上。
  判卷时没有做这件事。盲审通过了边界上命中的预测。

盲区 3:只检单步因果,不检多变量共变
  裁定了洛神的"因果链(情绪低→饥饿高→门控低)"看起来对,
  没有追问:这些变量之间有没有第三个共同驱动?
 unger 作为共同驱动同时影响情绪和门控上限,这个共变结构在洛神的推理里被忽略了,
  我也没有追问。

第 3 节:升级后的判卷 v4 裁定清单
---------------------------------------------------------------------

等洛神交 v4 归因分析时,追加以下 3 条裁定:

[M1] 量级闭合检验
  洛神给出新公式时,代入存货=0(最极端情景):
  - 饥饿分数 = tanh(h/20) = ? → z 的 term1 = ?
  - 能量供给率 = sigmoid((-200)/50) = ? → z 的 term4 = ?
  - z 的极值 = ? → sigmoid(z) 的极值 = ?
  这些数字跟洛神自己给的情绪实测范围对比,闭合才给过。

[M2] 动态稳定性检验
  洛神给的新公式,在 feed 节拍(每 3000 tick)振幅有多大?
  |情绪_max -情绪_min| 在一个 feed 周期内 < 0.05 才给过。
  否则就算趋势对,实际跑出来还是被节拍淹没。

[M3] 共变结构检验
  洛神给的相关性预测,必须画出变量依赖的有向图:
  末端变量 ← 直接驱动变量 ← … ← 原始输入(存货)
  检查两个被预测相关的变量,是否在图中存在共同祖先。
  若存在,预测必须改成条件相关或偏相关,不能简单写边际符号。
