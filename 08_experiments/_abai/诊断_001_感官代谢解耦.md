# 诊断 · 感官-代谢双系统解耦

> 只读排查令 · 引擎代码一字未动 · 依据 v7_envdiff 实测 + 行号锚定

---

## 一、排查对象

问题：七关（学·择·止·先·知·归·记）全部停在 0.5 月龄，"感官系统是否真的接入了引擎的内稳态代谢"。

假说的两面：
- **H1（感官已接入/已长好）**：环境差 → 引擎内生代谢（饿/醒/哭）可观测偏移
- **H2（感官未长好/断裂）**：环境差 → 引擎内生代谢无变化

v7 实测结果（两引擎同 seed=7 存货=0 TICK=60000，仅环境差 20%）：

| 项 | A_基线 (光90 温297) | B_扰动 (光72 温237) | 差 |
|---|---|---|---|
| 总激活 | 1.6454 | 1.9263 | **+17.07%** |
| 筋树数 | 7379 | 6952 | **-5.79%** |
| 饿 | 12.0 | 12.0 | **0** |
| 醒 | 1 | 1 | **0** |
| 哭合计 | 2000 | 2000 | **0** |

→ **H2 成立**。感知-可塑层对环境有结构性响应，但代谢时钟（饿/醒/哭）完全不动。

## 二、四条耦合链路逐条检查

### 链路 1：环境 → 激活（✓ 已接通）

```
环境["光"]  ─┐
环境["声"]  ─┤→ _推进() line 172-180：归一化
环境["力"]  ─┤→ line 195-207：末梢非线性 + 差变换 → 环境输入[5]
环境["温"]  ─┘
                   ↓
line 214: 隐藏输入[i] += 感受器[i][k] * 环境输入[k]
line 243: 新激活[i] = 激活[i] + 0.1 * 隐藏输入[i] + 噪声
```

v7 已证实：总激活差 +17%、筋树数差 -5.79%。感知确实在改变激活格局与筋树拓扑。

---

### 链路 2：饥饿 → 激活（✓ 已接通，反向）

line 244:
```python
新激活[i] += 0.6 * np.tanh(self.hunger / 8.0)
```

引擎的饿值会放大每个节点的基线激活（非线性饱和）。这是"饥饿驱动激活"的通道。

---

### 链路 3：激活/筋树 → 饥饿（✗ 断开）

`self.hunger` **唯一被写入的地方** = 轮末块 line 382-395：

```python
if self.时刻 % 10000 == 0:            # 只在回合边界更新
    round_num = self.时刻 // 10000
    is_feed = (round_num % 3 == 0)
    if is_feed:
        if self.存货 >= MEAL_COST:
            self.hunger = max(0.0, self.hunger - MEAL_CLEAR)
    else:
        self.hunger += DEBT_AWAKE if self.awake else DEBT_ASLEEP
```

结论：hunger 每 10000 tick 才改一次；修改量仅取决于"轮次"和"存货"；不看 激活/筋树/末梢/感知。

→ 激活层的任何波动（+17% 总激活、-427 根筋树）都不能改变 hunger 的轨迹。

---

### 链路 4：激活/筋树 → 觉醒（✗ 断开）

line 393-394:
```python
if self.hunger >= HUNG_CRY:
    self.awake = True
```

awake 的唯一翻转条件 = 饥饿过线（12.0）。不看激活幅值、不看筋树数、不看末梢差。

→ 即使激活很强（高驱动），只要 hunger < 12，awake 不回写。

→ 反过来说：hunger 到 12 时立即觉醒，也不看激活是否准备好。

---

### 链路 5：饥饿/觉醒 → 哭（✓ 接通，但是代谢时钟的终端）

line 248-252:
```python
if self.awake and self.hunger >= HUNG_CRY:
    self._哭计数 += 1
    if self._哭计数 >= 5:
        self.哭合计 += 1
```

哭是代谢时钟（hunger+awake）的终端输出，不感知、不读激活、不读筋树。

→ 任何改变"环境/感知/激活/筋树"的实验，在哭输出端只能看到：
- 哭何时启动（由 hunger 跨过 12 的时刻决定）
- 哭速率（由 awake+每-5-tick 硬门控决定）

而这二者都绑定 hunger 时钟，hunger 时钟绑定回合计数+存货，完全不读感知/激活层。

```
环境（光/声/力/温）

    ▼
末梢 + 差变换 + 感受器
    │ ✓
    ▼
激活 X(t) ───────────────────────────────────── 筋树拓扑
    │ ✓ (line 244: hunger→activation)             │ ✓（用进废退 line 331-357）
    │                                              │
    ╳  ← 不存在反向耦合                            ╳  ← 不存在反向耦合

饥饿时钟 ←→ 觉醒 ←→ 哭

```

左列（感知-可塑性系统）与右列（代谢节律系统）之间不存在有向耦合。

→ v7 数据完全符合此图：左列对差有响应（+17% 总激活、-5.79% 筋树），右列完全不动（饿/醒/哭三指标差=0）。

## 四、这是不是"没长好"

不是引擎没启动感知。感知已经激活并驱动了结构变化（v7 已证实）。

而是：感知驱动的结构变化**被封装在一侧**，没有形成对代谢节律的反馈。系统有**两个并行的动力学**：

| 子系统 | 由什么驱动 | 能改什么 |
|---|---|---|
| 感知-可塑 | 环境（光/声/力/温） | 激活格局 + 筋树拓扑 |
| 代谢节律 | 回合计数 + 存货 | 饿/醒/哭 |

七关里绝大多数"成长判据"（学、择、先、知、记）都要求"代谢时钟能被历史/预期/自指所偏移"。但代谢时钟只读回合计数和存货，是真正的"外源钟"——与感知无关。

---

## 五、"断脐验收"的含义

> 用户给该项目的验收题：把外源全撤掉，看它还在不在走。

"外源钟" = 代谢层的时钟（回合计数+存货+固定加债速率）。

现状：
- 外源钟停 → 饿/醒/哭全停。
- 撤外源后，还有"自源"可走的 = 感知-可塑系统（激活+筋树）。v7 已证实它在对环境变化持续响应。

所以：**"断脐"后，代谢层熄火，感知层仍能跑**。系统不是"无菌"，而是"半身不遂"——可塑性那半边还在长，代谢那半边靠外接电源。

## 六、实证预测（下一步可验证）

若本诊断正确，则以下三项预测应同时成立：

1. **预测 A**：把 hunger 与回合数解耦（改为 ∫激活 dt 驱动），引擎会丧失"准时哭"的稳定周期。
2. **预测 B**：把感知接入 hunger（如 环境["温"] 累加进 代谢速率），v7 的两引擎饿轨迹应出现偏差。
3. **预测 C**：若不动引擎、仅增大环境差（光/温 ±50% 而非 ±20%），两引擎饿/醒/哭仍应完全一致（因为耦合通道不存在，与幅度无关）。

预测 C 是当前诊断的"致命反例检验"——如果大温差能让饿轨迹偏，则诊断 3 有误；否则诊断 3 得到强化。

---

## 七、结论

七关结果（0.5 月龄×5 过×2）不是引擎"没长感官"，而是**感官长在了另一条管线上**。

感官系统（环境→末梢→激活→筋树）: **长好了**（v7 证实结构性响应）
感官接入代谢: **没长好 / 没接续**（断点：激活/筋树 → 饥饿 无有向耦合）

当前系统的七关"赝品检测"全部合格（证伪了心智赝品），成长停滞的原因不是感官缺失，而是**双系统之间缺乏代谢反馈通道**。
