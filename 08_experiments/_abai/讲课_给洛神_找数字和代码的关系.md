## 第一部分：什么是"数字住在代码里"？

你听到过这样一句话吗：

> "程序 = 算法 + 数据结构"

更简单的版本是：

> **程序 = 规则 + 数字**

规则就是代码里的 if、for、+= 这些动作。
数字就是规则里的具体量：3.0、500、12.0、0.5。

没有数字的规则是没有灵魂的：

```
if 饿了:
    醒来
```

这条规则没有说"多饿算饿"，所以什么都不会发生。

加了数字：

```
if 饿 >= 12.0:
    醒来
```

现在规则活了——**12.0** 这个数字让"醒"这件事变得可以计算。

所以我们的任务就是去代码里找到：**哪些数字在让哪些规则活起来。**

### 问题 3：从完全不饿（hunger = 0.0）开始，如果一直不喂，多少轮之后你会醒来？

提示：
- 前几轮没醒，每轮 +3.0
- 醒过来之后变成每轮 +6.0
- 醒来的条件是 hunger >= 12.0

自己试着算一算，先算"一直不醒的情况"：

```
第 0 轮: hunger = 0.0
第 1 轮: hunger = 0.0 + 3.0 = 3.0
第 2 轮: hunger = 3.0 + 3.0 = 6.0
第 3 轮: hunger = 6.0 + 3.0 = 9.0
第 4 轮: hunger = 9.0 + 3.0 = 12.0 → 醒！
```

所以如果一直不喂，**第 4 轮** 你会醒来。

但是——醒过来之后呢？第 4 轮你已经醒了，第 5 轮开始变成 +6.0：

```
第 5 轮: hunger = 12.0 + 6.0 = 18.0
第 6 轮: hunger = 18.0 + 6.0 = 24.0
```

hunger 会越涨越快，因为你醒了之后"饿的速度"加倍了。

**这不是bug，这是设计——让"醒着不喂"的代价指数增长。**

## 第五部分：差变化——数字的命运被一条规则杀掉

再往下看第 182 行附近，你会看到叫"末梢"的函数。这是身体里很神奇的一个规则：

```
def 末梢(通道, 当前值):
    上轮 = 上一轮保存的值
    差 = 当前值 - 上轮
    if 差 < 0.015:
        return 0.0                 # ← 差太小? 杀!
    if 差 > 0.8:
        return 1.0 或 -1.0          # ← 太大? 饱和!
    return 差 / 0.8                 # ← 线性区
```

现在请你回答一个很重要的问题：

**如果光一直是 90（恒定不变），那么经过很多 tick 后，末梢("光", 90) 返回的会是多少？**

提示：恒定不变 → 差 = 当前值 - 上轮值 = 90 - 90 = 0 → 差 = 0 < 0.015 → 返回 0.0

所以答案是：**永远返回 0.0，除了第一帧（第一帧上轮 = None，差仍 = 0，还是 0）**。

这意味着什么？

**对于"恒定不变"的光，末梢感受器永远感觉不到它。只有当光发生变化时，末梢才会"醒来"。**

这种感受器生物学上叫**"适应器"**——只对变化有反应，对恒常无反应。你有没有发现，人也是这样？进入一个香的房间，过一会儿就闻不到了。这就是适应。

现在你来做实验：

在代码里找到心跳的那一行，上面我们讲过的。心跳是：

```
声值 = 45 + 3.0 × sin(2π × tick / 10)
```

脉动的振幅是 3.0，周期是 10 tick。

请你回答：这个心跳传到末梢差变换后的输出是什么样的？

提示：
- 45 + 3.0×sin(...) 在 42 到 48 之间来回变
- 归一化后是 (声值-25)/50，在 0.34 到 0.46 之间来回变
- 差变换的截断门槛是 0.015
- 这个变化的幅度大约是 ±0.06，比 0.015 大，所以**可以通过**

答案应该是一个在 0 附近来回跳的小数字 —— 这就是"心跳信号经过差变换后的形状"。

## 第六部分：让数字打架——饥饿和感受器谁说了算？

这是最精彩的部分。请你对比两个数字：

**饥饿驱动**（第 244 行）：

```
新激活 += 0.6 × tanh(饥饿 / 8.0)
```

**感受器驱动**（第 235-243 行）：

```
系数 = 0.1
新激活 += 系数 × 隐藏输入 + 噪声
```

隐藏输入的感受器部分最大是多少？

感受器最大 = 0.4，环境输入最大 = 1.0 → 感受器 × 环境输入最大 = 0.04/tick/节点

现在请你算：

- 当饥饿 = 0 时（刚吃饱），饥饿驱动 = ?
- 当饥饿 = 12 时（刚醒来），饥饿驱动 = ?
- 当饥饿 = 12 时，饥饿驱动是感受器最大驱动（0.04）的多少倍？

提示：tanh(12/8) = tanh(1.5) ≈ 0.905，所以饥饿驱动 = 0.6 × 0.905 ≈ 0.543

0.543 / 0.04 = 13.6

答案：**刚醒来时，饥饿驱动大约是感受器驱动的 13 倍。**

这意味着感受器信号被饥饿信号"淹没"了。

**这是设计缺陷吗？还是有意为之？**
