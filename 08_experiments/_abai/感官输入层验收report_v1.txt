1. 代码层发现 (身体稳态.py 172-201 行)
---------------------------------------------------------------------

[1.1] 归一化公式 (光/声/力/温 各不同基准):
  光: max(0, min(1, (光-1)/500))        → 90→0.178, 1→0.0, 501→1.0
  声: max(0, min(1, (声值-25)/50))       → 45→0.4, 25→0.0, 75→1.0, 心跳±3
  力: max(0, min(1, (力-1)/30))          → 10→0.3, 1→0.0, 31→1.0
  温: max(0, min(1, (温-288)/15))        → 297→0.6, 288→0.0, 303→1.0
  最后那个 max(0,...) 导致 288K 以下全部 clip 到 0.0

[1.2] 末梢差变换 (仅"光"和"声", 不含力/温):
  def 末梢(通道, 当前值):
      差 = 当前值 - self.末梢上轮归一[通道]
      if abs(差) < 0.015:  return 0.0      # 高-pass: 稳态分量归零
      if abs(差) > 0.8:    return ±1.0      # 饱和
      return 差 / 高                         # 线性区
  → 差变换本质: d(normalized)/dt, 稳态信号全部 kill 到 0[第一帧除外]
  → 第一帧末梢上轮归一=None → 差=0 → 仍返回 0 (skip 而非传原值)

[1.3] 力/温通道行为:
  力: 归一后直接传入, 不经差变换 → 稳态分量能直接通过
  温: 归一后直接传入, 不经差变换 → 稳态分量能直接通过
  → 力/温的对比能力存在前提是: 归一后差 >感受器噪声带
  → 但感受器增益 ~U(-0.4,0.4), 系数=0.1 ← 感受器信号能进激活

4. 定性通道失效判据 (B: 扰1 与 基线 的差异)
---------------------------------------------------------------------

  [光] 信号路径: 环境"光"→归一→末梢差(kill稳态)→感受器→隐藏输入→激活
            现象: 90→72 只有帧边(第一帧tick1末光=0)有差异, 随后完全消失
            判定 ✗: 稳态不可达 (差变换的设计特性, 非代码 bug)
            备择: 需要动态光变化 (脉冲/闪烁) 才能驱动感受器

  [力] 信号路径: 环境"力"→归一→直接→感受器→隐藏输入→激活
            现象: 归一=0.3 恒常非零, 但 扰1 中力=10 保持不变 → 有力驱动但无对比
            判定 △: 通道本身 OK, 但 实验设计 未改变力 → 无法产生对比
            注: 48节点接感受器[2] ∈(-0.4,0.4), 感受器×0.3×系数0.1=0.006×sign

  [温] 信号路径: 环境"温"→归一(max0)→直接→感受器→隐藏输入→激活
            现象: 297→237 时归一 clip 到 0.0 (温<288→0)
            判定 ✗: clip 破坏负向差异, 只有温>288 时才有完整对比
            备择: 303 vs 297 → 归一 1.0 vs 0.6 (对比=0.4) → 可测

  [声] 信号路径: 环境"声"→叠心跳→归一→末梢差→感受器→...
            现象: 心跳 ac 通过 (±0.07 归一变化), 但稳态分量仍被 kill
            判定 △: 通道有高频驱动, 但实验条件声基线均为 45 → 无基线对比
            注: 声通道感受器只接脑1的 24 节点 感受器[i][1]

5. 代码层判定: 是不是 "BUG"?
---------------------------------------------------------------------

[5.1] 末梢差变换 (光/声走差变换, 力/温不走):
  身体稳态.py 注释: "末梢: 声(1)/光(0)走差变换, 力(2)/温(3)保持原值"
  → 这不是代码 bug: 注释说明是"保持原值", 差变换在光/声上是有意设计
  → 但 末梢() 函数第一帧上轮=None 跳到了 差=0, 而非传原值
    (如果首帧传原值而非 0, 光/声也会在 tick=1 获得一个初始对比脉冲)
  → 影响范围: 仅第一帧, 稳态后仍无法区分恒常信号

[5.2] 温归一化的 clip:
  max(0.0, ...) 把 288K 以下全部归 0 → 破坏负向差异
  → 是否是 bug 取决于设计意图:
    - 如果引擎需要表达"冷", 应该 min<0 或 offset>288
    - 如果引擎只需要表达"热感", 这是设计剪枝
  → v7/v7b 实验条件: 297(基线) vs 237(扰1)
     → 温归一 0.6 vs 0.0 → clip 主导(完美对比, 但已到 0 地板)

[5.3] 感受器范围 & 系数:
  感受器 ∈ (-0.4, 0.4), 系数 0.1 → 感受器贡献最多 0.1×0.4=0.04/tick
  饥饿贡献: 0.6×tanh(hunger/8) ≥ 0.6×tanh(12/8)=0.53/tick (觉醒后)
  → 感受器 与 饥饿 的驱动强度比约为 1:13 (饥饿主导)
  → 感受器信号能进激活环路, 但被饥饿噪声带埋没

6. 用户怀疑的裁决: "代码错误导致没有对比" → 部分成立
---------------------------------------------------------------------

[6.1] 代码 "设计" 而非 "错误":
  末梢差变换在光/声: 是注释明确的设计
  温 clip 在 288K: 是数学设计, 但负温差无法表达 ⚠
  感受器小系数: 是设计参数, 但饥饿贡献远强于感受器

[6.2] 真正的阻碍对比的原因:
  (a) 光/声通道设计让稳态信号归零 → 这就是"没有对比"的呈现
  (b) 力/温通道可以让稳态信号通过 → 但实验中力罕见变化 ⚠
  (c) 温归一负温差 clip 在 0 → 低温侧无法区分 ⚠
  (d) 觉醒后饥饿贡献 >> 感受器贡献 → 信号进激活但被埋 ⚠

[6.3] 因此用户怀疑的"代码错误导致无对比"溯源:
  √ 末梢差变换是"无稳态对比"的首要代码机制 (非 bug 但是设计结果)
  √ 温 clip 阻止负温差 (有条件的 bug)
  ✗ 感受器系数小是"感弱但非无感"
  ✗ 环境反向实验 R0/R1 在力/温上的参数选择 正好落在 clip 区

7. 数值给直接证据: R0 (基线) vs R1 (扰1) 的激活链路
---------------------------------------------------------------------

  R0: 光=90 声=45 力=10 温=297
   末光=0, 末声∈[-0.044,0.044] (心跳, 10 tick 周期)
   力稳=0.3 (48节点恒驱)
   温稳=0.6 (24节点恒驱)
   → 净感受器驱动 = 感受器_distribution × [0, ac, 0.3, 0.6]

  R1: 光=72 声=45 力=10 温=237
   末光=0 (除帧边2帧外)
   末声同 R0
   力稳=0.3 (同 R0)
   温稳=0.0 (clip, 237<288)
   → 净感受器驱动 = 感受器_distribution × [0, ac, 0.3, 0.0]
   → 唯一差异: 温通道贡献由 0.6→0.0 (24节点感受器温[i]×0.6×0.1=...)
   → 每 tick 激活差 (感受器贡献): 24×avg(|感受器[温]|)×0.6×0.1
     感受器[温] ∈U(-0.4,0.4), avg(abs)≈0.2
     → 每 tick Δ激活 ≈ 24 × 0.2 × 0.6 × 0.1 = 0.288
   → 100 tick 后 Δ激活 ≈ 28.8 (扣门控缩放后<10)
   → 这是 v7/v7b 中 R1 激活总量较高的原因 (温通道17%↑)

8. 下一步验证设计
---------------------------------------------------------------------

[8.1] A/B 温对比 (有效通道, 无 clip):
  A: 温=297 (归一=0.6); B: 温=303 (归一=1.0); 同样力=10 光=90
  → 预期: 激活差 = 感受器×(1.0-0.6)×0.1 ≈ 24×0.2×0.4×0.1=0.192/tick
  → 应≠0, 应可被 total_activation / sinew 抓到

[8.2] A/B 力对比 (有效通道, 无 clip):
  A: 力=10 (归一=0.3); B: 力=15 (归一=0.467)
  → 预期: 激活差 ≈ 48×0.2×0.167×0.1=0.160/tick
  → 48节点感受器[i][2] ∈U(-0.4,0.4)

[8.3] A/B 光脉冲 (切换差变换):
  A: 光=90 (稳态, 末光=0); B: 光 在 90↔20 间每 100 tick 切换
  → 预期: B 每次切换检测到末光=±(0.178-0.038)=±0.140 (触发高-pass)
  → 这是唯一能让光通道产生稳态对比的输入模式
