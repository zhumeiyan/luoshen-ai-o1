模块 1: 常量束 (文件顶部, L9-19)
---------------------------------------------------------------------

[1.1] 饥饿代谢
  FEED_EVERY = 3                → 每 3 轮喂一次 (轮 = 10000 tick)
  DEBT_ASLEEP = 3.0             → 没醒时, 每轮 hunger += 3.0
  DEBT_AWAKE = 6.0              → 醒着时, 每轮 hunger += 6.0
  MEAL_CLEAR = 8.0              → 喂一次, hunger -= 8.0
  HUNG_CRY = 12.0               → hunger >= 12.0 时 awake=True (觉醒线)
  关系: 饿钟的"走速" = 3.0(睡) 或 6.0(醒) / 轮; 喂能 -8.0;
       醒后越走越快(3→6)直到 12 触发哭

[1.2] 心跳供给
  HEARTBEAT_AMP = 3.0           → 叠在"声"上的正弦振幅 = 3.0
  HEARTBEAT_PERIOD = 10         → 正弦周期 = 10 tick
  MEAL_COST = 4                 → 喂一次扣存货 4
  关系: 声 = 45 + 3.0×sin(2π × tick/10); 周期内归一变化 ±0.044

[1.3] 引擎全局
  上限满值 = 6.0                → 门控上限未受压时的初始目标
  温度满值 = 1.5                → 热量/1.5 = 温度饱和度 → 反压上限
  功耗满值 = 15.0               → 活跃节点数/15.0 = 功耗饱和度
  节点数 = 96                   → 4 脑 → 每脑 24 节点
  冷却 = 3                      → 节点过 0.5 后不应期 3 tick
  关系: 实际门控上限 = 6.0 × (1 - max(内存饱和度, 温度饱和度, 功耗饱和度))

模块 2: 感受器与脑通道分配 (init)
---------------------------------------------------------------------

  4 脑, 每脑 24 节点, 4 感受器/节点 (对应 5ch: 光/声/力/温/回接)
  感受器[i][k] ∈ U(-0.4, 0.4)  ← 系数 = 0.1 × 环境输入(k)

  脑 0 (节点 0..23):   感受器接 光[0] + 力[2] (双通道)
  脑 1 (节点 24..47):  感受器接 声[1]
  脑 2 (节点 48..71):  感受器接 力[2] (所以"力"共 48 节点感受器)
  脑 3 (节点 72..95):  感受器接 温[3]

  关系: 力在引擎里占的感受器节点数是其他通道的 2 倍 (48 vs 24)

模块 3: 归一化 (L173-178)
---------------------------------------------------------------------

  光:  max(0, 1, (光 - 1.0) / 500)
  声:  max(0, 1, (声值 - 25.0) / 50)      其中声值 = 45 + 3.0×sin(2πt/10)
  力:  max(0, 1, (力 - 1.0) / 30)
  温:  max(0, 1, (温 - 288.0) / 15)

  关键数字对:
  物理值 → 归一值 → 反推
  光: 1→0, 501→1, 90→0.178
  声: 25→0, 75→1, 45→0.4
  力: 1→0, 31→1, 10→0.3
  温: 288→0, 303→1, 297→0.6

  归一后的 clip: 下界 0.0, 上界 1.0
  ⚠ 温: 288K 以下全部 clip 到 0.0 → 负温差不可表达
  ⚠ 光: 1 以下 clip 到 0

  关系: 把 4 个不同物理量映射到同一个 [0,1] 感受器输入区间

模块 4: 末梢差变换 (L182-193, 仅 光/声)
---------------------------------------------------------------------

  def 末梢(通道, 当前值):
      上轮 = self.末梢上轮归一[通道]
      差 = 0.0 if 上轮 is None else 当前值 - 上轮
      槛 = self.末梢[通道]
      if abs(差) < 槛["低"]:     return 0.0        # 截断
      if abs(差) > 槛["高"]:     return ±1.0        # 饱和
      return 差 / 槛["高"]                           # 线性区

  槛参数:
      声: 低=0.015, 高=0.8
      光: 低=0.015, 高=0.7

  关键数字行为:
  - 第一帧: 上轮=None → 差=0 → 必返 0 (跳过而非传原值)
  - 稳态后(恒常输入): 差=0 → 截断 → 0
  - 心跳 ac(10 tick 周期): 差 ∈[-0.044, +0.044] >0.015 → 线性区 ±0.055

  关系: 末梢 = d(归一后的通道)/dt, 高-pass 滤波

模块 5: 感受器 × 环境输入 → 隐藏输入 (L210-214)
---------------------------------------------------------------------

  for i in 96 节点:
      for k in 5 通道:
          隐藏输入[i] += 感受器[i][k] × 环境输入[k]

  环境输入 5ch 组成:
      ch0 = 末光 (末梢差光)
      ch1 = 末声 (末梢差声)
      ch2 = 力归一 (直接)
      ch3 = 温归一 (直接)
      ch4 = 回接差 / 20.0 (上轮激活差, 20 个回接节点之和)

  关系: 隐藏输入[i] = Σ_k 感受器[i][k]·env_in[k], dot product

模块 6: 筋树传导 (numba加速, _传导加速 L24-40)
---------------------------------------------------------------------

  信号 = 筋_位点[k] × 筋_疲劳[k] × 激活[j] × 传导差[j]
  延迟缓冲: FIFO 延迟 = 筋['延迟'], 头出尾进
  隐藏输入[i] += 到达信号  (位移后由延迟缓冲弹出)

  筋字段: 位点, 疲劳, 延迟, 生辰, 末传
  位点初值: 3
  疲劳初值: 1.0
  传导衰减: 每 200 tick, 50% 概率 ×0.9
  废退: 若 tick - 末传 > 5000 且 %1000==0, 位点 -= 1
  修剪: 位点 <= 0 时整条筋移除

  关系: 筋树是"可塑性", 激活历史的物理痕迹; 用进(传导) × 废退(不传导)

模块 7: 激活累积 (L234-246)
---------------------------------------------------------------------

  X(t+1) = X(t) + η·隐藏输入 + ε + 0.6·tanh(hunger/8)

  系数 η = 0.1
  噪声 ε = U(-0.01, +0.01)
  饥饿驱动 = 0.6 × tanh(hunger / 8.0)
  不应期冷却 = 3 tick (过 0.5 后触发)
  过 0.5 → new[i] = 当前值 × 1.0 (不应期不进累积)

  关键数字链:
  当 hunger=12 (饿醒阈值), 饥饿驱动 = 0.6×tanh(1.5) ≈ 0.6×0.905 = 0.543/tick
  当 hunger=6,                 饥饿驱动 = 0.6×tanh(0.75) ≈ 0.6×0.635 = 0.381/tick
  感受器贡献 max = 0.1 × 0.4 = 0.04/tick/节点
  饥饿贡献 : 感受器贡献 ≈ 0.5 : 0.04 ≈ 13 : 1

  关系: 激活 = 慢变量(积分器), 饥饿是强驱动(~13×感受器)

模块 8: 门控缩放 (L256-275)
---------------------------------------------------------------------

  总激活 = Σ|新激活[i]|
  if 总激活 > 当前上限:
      门控激活 = 新激活 × (当前上限 / 总激活)     # 等比压缩
  else:
      门控激活 = 新激活                             # 直通

  热量 = Σ (门控激活[i])²
  活跃节点数 = count(|门控激活[i]| > 0.1)
  温度饱和度 = 热量 / 1.5
  功耗饱和度 = 活跃节点数 / 15.0
  内存饱和度 = 筋树数 / (96×95)
  压力 = max(内存饱和度, 温度饱和度, 功耗饱和度)
  目标上限 = 6.0 × (1.0 - 压力)
  当前上限 ← 0.9 × 当前上限 + 0.1 × 目标上限    # 平滑

  关系: 当前上限是慢变量, 受温度+功耗+内存三重反压;
        门控只是把总激活限在当前上限以内, 不压缩形状

模块 9: 共火(筋树生长) (L294-336)
---------------------------------------------------------------------

  脑内共火: 同一脑内有 ≥2 节点, |激活差| > 0.01
            连筋概率 = 0.15
  跨脑共火: 两脑各有 ≥1 节点, |激活差| > 0.02
            连筋概率 = 0.05
  首拍跳过 (第一拍不连筋)
  每节点至多 1 新筋/拍

  关系: 共火 = "一起放电的节点会长出连接"(Hebb 学习的时间差版本)

模块 10: 哭与回合计量 (L382-395)
---------------------------------------------------------------------

  每 10000 tick = 1 轮
  if 轮 % 3 == 0:
      if 存货 >= 4:  hunger -= 8; 存货 -= 4
  else:
      hunger += 3.0(没醒) 或 6.0(醒了)
  if hunger >= 12.0:  awake = True
  (轮末记快照)

  哭: if awake==True 且 hunger>=12: 每 5 tick 记 1 声哭
  哭速率: 5 tick/声 = 0.2 声/tick (恒常, 不分化)

  关系: 回合是离散钟, 数值变动在 tick=10000, 20000, 30000...
        哭是被 awake+过线 双门控制的恒速打点器

模块 11: 自己点 / 回接 (L397-end)
---------------------------------------------------------------------

  每 1000 tick: 从回接节点所在筋树簇选节点 +0.5
  沉淀: 若上次|反馈差|≥0.1, 续点同节点 (×0.9 脱开概率)
  换节点: 上次差<0.1 或 节点不可用 → 换新的回接节点
  回接节点 20 个 (自指簇)

  关系: 自己点是"内稳定器", 让回接簇的激活保持在 ~0.5 左右
