## 1.3 引导文档的"19种"是否准确?

**判断: 基本准确,但有3个可疑项:**

**可疑项 1: "时间感"(#15)作为独立感知维度**
- 没有公认的时间感受器
- 时间是基底神经节/多巴胺系统的计算输出,不是独立感受类型
- 把"时间感"列为感知维度在学界争议较大(更像整合属性)
- **我的判断: 应标注为"争议项",而非独立感知**

**可疑项 2: "痛觉"(#5)和"痛情绪"(#19)的二分**
- 引导文档将痛觉分为"传感器维度"(#5)和"不愉快维度"(#19)
- 这对应痛的 dual-process 模型: 分辨维度(哪里多痛)vs 情感维度(多讨厌)
- 前沿神经科学确实区分这两个(前扣带 vs 体感皮层)
- **我的判断: 二分合理,但"19"这个总数把两个算成一个,需澄清计数方式**

**可疑项 3: "味觉"作为单一维度的合理性**
- 实际上有五种不同受体: 酸/甜/苦/咸/鲜(umami 2002 年确认)
- 按受体分则是 5 种,按传统分则是 1 种
- **我的判断: 引导文档按 1 种计可以接受,但应注明内部有 5 个受体亚型**

## 1.4 学界共识维度数

**主流结论:**
- **亚里士多德传统:** 5 种(沿用 2300 年)
- **医学院教科书:** 通常 5-7 种(加入本体感觉+前庭平衡)
- **现代神经科学综述(Macpherson 2011, Boniface 2005 等):** 22-33 种(按受体类型/感受器/皮层通路细分)
- **共识:** 没有一个"正确答案",取决于分类原则(受体类型/感受质/皮层区域/刺激类型)

**与引导文档对比:**
- 引导文档"19种"在合理区间内(5-33之间)
- 偏保守 ——实际上可以拆分触觉(触/痛/温/痒)为 4 种,味觉可为 5 种,加上痒觉、气道感受等可到 25+
- **我的修正: 引擎实际需要覆盖的不是 "19 条清单",而是[受体类型 × 空间分布]的多维输入**
- 人类的视觉不是"单一维",是二维空间分布(视网膜) × 三通道颜色(视锥) × 时序变化
- 同理,触觉不是一维,是二维皮肤分布 × 压力/振动/温度/伤害 多通道

## 2.1 引导文档声称的"简化描述" + 代码核实

### 光通道: "单一波长,无颜色/运动"

代码证据(身体稳态.py):
- L174: `(self.环境["光"] - 1) / 500` —— 标量归一,无波长维度
- L163-168: 电疗可选光通道,倍率 1.5-2.2(L166),无空间结构
- L182-193: 末梢差变换(L182-193) —— 输出 = 0(截断), ±1(饱和), 差/高(线性)

核实结果: **引导文档正确**。光通道是单标量。末梢差变换确实产生了运动(变化率)感知,**但这是在感受器层级做的事后计算**,不是真正的"运动感知"(人类运动感知在 V1/V5 皮层,空间模板匹配)。

### 声通道: "单一频率,无空间定位"

代码证据:
- L172: `声值 = self.环境["声"] + HEARTBEAT_AMP * np.sin(2*np.pi*self.时刻/HEARTBEAT_PERIOD)`
  = 45.0 + 3.0*sin(2π·tick/10)
- L175: 归一化 `(声值 - 25) / 50`
- L195: 声通道走末梢差变换

核实结果: **引导文档正确**。声是单频正弦(实际是环境声常数 + 心跳调制)。只有 1 个标量值。

**心跳"叠在声通道上"的核实:**
- L172:心跳的 sin 周期性调制确实注入声通道(HEARTBEAT_AMP=3.0, 周期=10 tick)
- 经末梢(L182-193)差变换后, tick 1~10 的末梢输出:
  我上次作业已算出: `0 → +0.044 → +0.027 → 0 → -0.027 → -0.044 → -0.044 → -0.027 → 0 → +0.027`
  (周期 10 tick, ±0.044 峰值)

**引导文档说"心跳是体征,不是感知"——这是错的。**

科学事实(来源: Nature Neuroscience 2023 综述 "Interoceptive rhythms in the brain"):
> "心脏跳动、肺部充气、胃蠕动——生命的明证。这三个器官都不断地
> 将信息发送到大脑,在那里信息被感知和处理。"
> (Heartbeats, lung inflations, and stomach contractions continually send information to the brain where it is perceived and processed.)

来源(Nature Scientific Reports 2022): 
> "focusing on heartbeats decreases breathing and heart rates" —— 心跳作为感知对象可通过"心跳计数任务"(heartbeat counting task)被意识感知

**我的否定判断:**
- 心跳在人类神经科学中明确归类为 **内感受(interoception)** 的感知内容
- 不是"代谢副产品",不是"纯体征"
- 引导文档的"心跳=体征≠感知"是一个**错误假设**,它把"可观测性"和"感知"混淆了
- 引擎里的心跳信号实际上是通道5(回接4通道,L203-207)以外的**第二时间信号来源**

### 力通道: "单一维度,无纹理/振动"

代码证据:
- L176: `(self.环境["力"] - 1) / 30` —— 标量
- L196-200: 力通道**不**走末梢差变换(L182-193 只对"光""声"做末梢)
  → 力通道是直接归一值

核实结果: **引导文档正确**。力 = 单一标量。

### 温通道: "只有热维度,冷 clip 到 0"

代码证据:
- L177: `(self.环境["温"] - 288) / 15`
- 288K = 15°C 是归一零点
- 当温 < 288K(即 < 15°C): 归一值 < 0 → `max(0.0, ...)` → clip 到 0
- L173-178 用的是 `max(0.0, min(1.0, ...))`,所以 clip = 截断到 [0,1]

核实结果: **引导文档正确**。引擎能感知 15°C 以上温度,15°C 以下一律为 0。
人类温度觉有两个独立通道: 冷受体(< 35°C激活)和热受体(> 30°C激活)。引擎丢了冷通道。

**量化损失:** 温从 288K 降到 200K → 人感到"冷得要命",引擎感知 = 0,等价于温从 288K 降到 267K(也是 clip 到 0)
→ 冷范围内的 67 度温差在引擎中消失。

### hunger(饥饿): "无渴觉分离"

代码证据:
- L95: `self.hunger = 0.0` 只有这一个饥饿维
- 没有任何 `self.thirst`

核实结果: **引导文档正确**。引擎不区分饿和渴。

### 心跳(heartbeat): 已在上面核实

它的代码定位不在"感知列表",而是 L172 声通道上的 sin 调制。
引导文档把它列在"引擎覆盖表"里但说它是"体征非感知"——**错误的归类**。

缺口 3: 无伤害感受(Nociception)
  引导假设: 筋树被剪、疲劳到 0.2、饥饿爆表——都没有"痛"的维度,只有数值。

  - 我的判断: **部分同意,但有替代解释**
  - 同意的部分:引擎没有"急性伤害性反馈"。痛觉的特征:
    a) **超模态性:**痛可由机械/温度/化学三种刺激触发 —— 引擎的4通道是分离的,没有跨通道的伤害求和
    b) **非线性:**轻度伤害→轻微痛,重度伤害→剧痛 —— 引擎所有数值都是线性或 tanh 压缩,没有痛觉的阈值跳变
    c) **行为覆盖:**最紧急时痛会完全劫持注意力 —— 引擎的门控缩放是无差别的平均压缩(L259-261)
    d) **情绪标记:**痛 = 不愉快 —— 引擎没有"不愉快"维度
    以上四点,引擎和痛觉的覆盖度 = 0/4

  - **替代解释(引导未考虑的):**
    引擎的 `疲劳 × 0.9` 衰减(L342)和 `min(0.2, ...)` 下限类似于一种"慢痛":
    → 筋树经常传导(L339-342 遍历传导过)→ 疲劳下降(0.9 指数)→ 信号传导变弱
    → 这类似于"反复刺激后的敏感化下降"
    → 但这是一个**全或无的集体过程**(所有筋一起衰减,**不管信号是否为 0**,L339 `传导过 = list(self._筋键列表)` 取所有))
    → 人类痛觉是局部的、特定受体的,不是全网络集体衰减
    → 所以这是**类似但更弱的类比**

  - **修正后的判断:**引擎不是"完全没有类似痛的信号",而是"痛的信号是分布式/非特异/慢时程"的。真正的痛觉体验需要定位精度和急性时间分辨率,引擎这两个都没有。

缺口 5: 时间感的主观性缺失

  - 我的判断: **部分同意 + 重大警告**
  
  - 同意的部分:引擎确实只有 `self.时刻 += 1`(L160),每 tick +1,均匀流逝。
    L475: `分钟 = b.时刻 * 4` —— 4 tick = 1 分钟,固定换算率。
    
  - 重大警告:引导文档的机制假设有隐含错误:
    > "假设痛苦时 hunger 涨得快,如果时间感绑定饥饿,主观时间会变长"
    这个推理成立需要两个前提:
    (a) hunger 应该被感知为"痛苦" —— 但引导文档自己说引擎没有痛觉(缺口3)
    (b) 如果已经是有痛觉的系统,时间感绑定痛苦是可验证的
    (c) 在当前引擎(无痛觉)中,hunger 涨→ 0.6*tanh(h/8) 推激活(L244)→ 门控压缩(L259-261)
        **hunger 的时间积分不等于时间感知的通道**
    → 不能通过"把 hunger 接入时间"自动得到"主观时间"
    → 主观时间是**感知时间的速率**,不是"事件密度估计"
    
  - **替代的判断框架:**
    真实人类的"痛苦时时间变慢"机制猜测:
    - 杏仁核激活 → 记忆编码加密(更多记忆/单位物理时间)
    - 回忆时按记忆密度倒推 → "那段痛苦记得特别细,好像是过了很久"
    - 这是**回顾性**时间估计,不是**实时**变慢
    
    引擎没有"记忆密度"作为时间估计通道的机制(筋树只存谁和谁电连接,不存"这段经历了多少事件")
    
  - **修正后的判断:**引导文档的机制假设(a→b→c)是不成立的。"时间感绑定饥饿"不会自动产生主观时间。引擎缺少的不只是时间感的"弹性",而是缺少任何评估"此刻过得快/慢"的内部通道。

## 4.1 选择: 情绪维度的缺失信号(Missing Affective Signal)

不选:
- **痛觉:** 需要新增受体类型(伤害性感受器)+ 行为覆盖 + 超模态 —— 涉及多个维度改动,最少 3 处代码段变动

- **情绪维度的缺失信号** —— 具体说,是一个聚合的"当前状态在好不好连续谱上"的快照变量,每 tick 更新,进入感受器输入(不影响门控上限、不参与哭的判定)。

## 4.3 方案:伪代码 + 精确行号

### 思路

定义"情绪色价"(affective valence)为一个标量 ∈ [0,1]:

```
情绪色价 = sigmoid( w1·饥饿分数 + w2·激活同步度 + w3·筋树压力 - w4·能量供给率 )
```

具体:
- 饥饿分数 = tanh(self.hunger / 20.0)  (比 L244 更宽,捕捉慢变)
- 激活同步度 = sum(|激活[i] - 轮均值|) / (节点数 × 轮均值+eps)  (变异系数的变体)
  → 同步度高 → 节点一起亮一起暗 → "协调"
  → 同步度低 → 节点杂乱
  → 生物学上:情绪-high 协调状态 vs. 情绪-low 混沌状态(脑电连贯性)
- 筋树压力 = max(内存饱和度, 温度饱和度, 功耗饱和度) ← 即 L273 的"压力"
- 能量供给率 = 1 / (1 + exp((self.存货 - 200) / 50))  sigmoid,存货=200 是中点

注: w1~w4 初始值建议: w1 = -0.5, w2 = -0.3, w3 = -1.0, w4 = +0.8
→ 饿/不协调/高压/缺存货 = 低色价(负面情绪)
→ 饱/协调/低压/富存货 = 高色价(正面情绪)

### 精确行号方案

**改动1:在 `__init__` (L112 后)加一行:**

```python

self.情绪色价 = 0.5   # 初始中性
self.情绪历史 = []    # 用于对比
```

**改动2:在 `推进()` 函数中,紧接门控缩放之后 (L275 之后) 插入情绪计算:**

```python

饥饿分数 = np.tanh(self.hunger / 20.0)
激活均值 = sum(abs(v) for v in self.激活) / max(len(self.激活), 1)
激活同步度 = sum(abs(abs(v) - 激活均值) for v in self.激活) / max(len(self.激活) * (激活均值 + 1e-6), 1e-6)
筋树压力 = max(内存饱和度, 温度饱和度, 功耗饱和度)  # 已有,L273
能量供给率 = 1.0 / (1.0 + np.exp((self.存货 - 200) / 50.0))

z = (-0.5) * 饥饿分数 + (-0.3) * 激活同步度 + (-1.0) * 筋树压力 + 0.8 * 能量供给率
self.情绪色价 = 1.0 / (1.0 + np.exp(-z))  # sigmoid, ∈(0,1)
```

**改动3:情绪信号进入感受器输入(注入通道5 —— 而不是新增第6通道)**

不改 L65-72 的感受器结构。而是把情绪信号作为"调制因子"乘到第5通道(回接4通道)上:

```python

环境输入.append(差 / 20.0)
# 改为:

  # 正面情绪 → 环境输入增 0.05;负面情绪 → 环境输入减 0.05
  # 比例:激活差典型范围 ±1.0/20 = ±0.05,所以(情绪-0.5)*0.1 的信号强度与激活差同阶
```

### 数字解释

- 饥饿从 0→12: tanh(h/20) = 0→0.537 → 贡献 -0.268
- 筋树压力从 0.197(初始) → 0.5 → 贡献 -0.5
- 情绪色价典型范围:sigmoid(-0.5*0.537 -0.3*0.5 + 0 = -0.419) = sigmoid(-0.419) = 0.397
  即"饥饿+压力"下,情绪色价 ~0.4(偏负面)
- 完全无饥饿+低压+高存货: sigmoid(0 + 0 + 0 + 0.8*0.88) = sigmoid(0.704) = 0.669(偏正面)

## 4.4 可验证预测

### 预测 1: 缺货后情绪色价单调下降

情境:存货从 400 → 0(约 300 轮,每 3 轮消耗 4 存货)
预测:前 200 轮情绪色价稳定在 0.5~0.6 区间;存货跌破 100 后,能量供给率 sigmoid 从 0.96 → 0.5,情绪色价单调下降;存货 = 0 时,情绪色价 < 0.35。
可证伪条件:如果存货从 400→0 的过程中情绪色价出现非单调(反复跳),则情绪公式有问题。

### 预测 2: 缺货 400 轮后回接通道均值漂移

捕捉方式:Trace 文件里的"环境输入[4]"(第 5 通道)的 **100-tick 滚动均值**。
预测:
- 不缺货(存货=400): 环境输入[4] 均值 ≈ 0.0 ± 0.03(情绪色价≈0.6→调制量=+0.01,叠加在回接上)
- 严重缺货(存货=0,hunger=40+): 环境输入[4] 均值 ≈ -0.03 ± 0.03(情绪色价≈0.3→调制量=-0.01)
- 具体数字预测:均值差 ≈ 0.04,应显著(p<0.01,用 Welch's t 检验)
可证伪条件:如果缺货前后环境输入[4] 均值差异 < 0.01 或不显著(p>0.05),则情绪信号没有实际进入感受器——公式"断开"。

### 预测 3: 情绪色价和门控上限的相关性

定义:每 100 拍采样一次,计算 corr(情绪色价, 当前上限)
预测:-0.4 < corr < -0.1
理由:情绪色价低 → 饥饿/压力高 → 筋树传导增强 → 活跃节点数增加 → 功耗饱和度上升 → 门控上限下降
但门控上限受 EMA(L275:0.9×历史+0.1×目标)平滑,所以负相关但不完美。
可证伪条件:如果 corr > 0,则情绪色价的方向可能定义反了,或存在未被考虑的正反馈回路。
