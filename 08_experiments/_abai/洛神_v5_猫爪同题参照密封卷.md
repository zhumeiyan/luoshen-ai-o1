新情绪公式 v5(只依赖阶段 ①② 之前的变量):

  设 hunger_tick = self.hunger(当前 tick 回合更新前的值)
  设 sinew_成员数 = len(self.筋树)

  饥饿分数_v5 = tanh(hunger_tick / 12.0)
                用 /12 而非 /20(人类饥饿感在满 12.0 时已经很强烈,
                tanh(12/12)=tanh(1)=0.76,留一点余量给极端场景)

  结构应力分 = 内存饱和度
              = len(self.筋树)/(节点数×(节点数-1))
              = len(self.筋树)/9120
              (筋树健康状况的代理量,不依赖 L274 之后的压力计算)

  能量供给率_v5 = 1.0 / (1.0 + exp((self.存货 - 60) / 30.0))
                 中点从 200 降到 60(洛神存货满值是 400,
                 但多数时候在 0-60 之间波动。对数中点贴近实际工作区间)

  z_v5 = -0.6×饥饿分数_v5 + 0.2×结构应力分 + 0.5×能量供给率_v5

  情绪色价_v5 = sigmoid(z_v5)

被砍掉的两个 term(洛神需要解释 why):

1. 肌树压力(原权重 -1.0):
   - 依赖 L274 `压力 = max(内存,温度,功耗)`,其中温度/功耗依赖门控后的激活
   - 门的输出反馈回输入 = 自引用环
   - 放在感知层会让"感知"里包含"激活处理后的结果",违反"感知应独立于皮层加工"的类比

2. 激活同步度(原权重 -0.3):
   - 依赖 self.激活(L288 `激活 = 门控激活`)
   - 激活是门控后的输出,如果把激活同步度反馈回感知层,
     等于让"你看到的世界"包含"你上一次加工过的世界"
   - 情绪感知成了加工的 downstream 而不是 upstream

偏差分析:
- 半饥饿:猫爪比洛神低 0.046。原因:猫爪能量供给率的中点调到了 60,
  存货=8 时 sigmoid 更低,拉低了能量项。同时猫爪饥饿权重从 -0.5 提到 -0.6,
  饥饿分数项贡献更大。两因素叠加使半饥饿时猫爪情绪更低。
- 纯缺:猫爪 0.411 > 洛神 0.366。原因:猫斧砍掉了压力项(-1.0),
  压力在纯缺时是最大正值提供者。砍掉后情绪不再被压力"压低"。
  符合预期——纯缺时"压力"来自门控输出反馈,不应计入情绪感知层。

猫爪自检:我这答案里有没有"自己挖的坑"?
---------------------------------------------------------------------

坑 1:能量供给率 sigmoid 中点选 60。依据是什么?
   - 存货初值 400,每 3 轮喂 1 次每次扣 4,从 400→0 要 300 轮。
     但实际 tick 从存货 20 开始(我的实验设定)。工作区间通常在 0-60,
     所以 60 作为 sigmoid 中点合理。但如果洛神用"满存货 400 开局",
     中点 60 就不合理(满存货时能量供给率接近 1.0,情绪被能量项主导)。
   - 这个参数需要实验校准,60 是一个"凭经验"的初值。
   - 扣分:猫爪凭经验选参,没给理论推导。洛神应追问。

坑 2:结构应力分用 len(self.筋树)/9120,这是"绝对筋树数"而不是"饱和度变化率"
   - 筋树数在一个 feed 周期内基本不变(共火对有激活差才触发,概率低)
   - 只有长时间 tick 后筋树密度才改变
   - 这意味着结构应力分在短期(几 tick 到几十 tick)几乎是常量
   - 它给情绪贡献 ~0.04,是个"偏移量",不是动态驱动力
   - 扣分:猫爪用一个近似常量去模拟两个被砍掉项(压力+同步度)的动态效果,
     逻辑站不住。洛神应追问"砍掉动态项后用静态项补,情绪还有时间结构吗?"

坑 3:情绪权重从 v3 的 [-0.5, -0.3, -1.0, +0.8] 改成 [-0.6, +0.2, +0.5]
   - 饥饿权重从 -0.5 加到 -0.6:让饥饿对情绪的贡献更大(更像"感知层应该的饥饿感")
   - 压力项 -1.0 彻底砍掉:不在感知层
   - 同步度项 -0.3 彻底砍掉:不在感知层
   - 新增结构应力分 +0.2:填补砍掉两项后的"空白"
   - 能量供给率从 +0.8 降到 +0.5:降低能量对情绪的主导权(留空间给饥饿)
   - 扣分:权重调参是试出来的。洛神应当用"微调一个权重看情绪变化幅度"的方式
     实测,而不是猫爪这样一次改三个参。
