[模块 4:末梢差变换 L182-193,仅 光/声]

  槛: 声 低=0.015 高=0.8; 光 低=0.015 高=0.7

  def 末梢(通道, 当前值):
      上轮 = self.末梢上轮归一[通道]
      差 = 0.0 if 上轮 is None else 当前值 - 上轮
      槛 = self.末梢[通道]
      if abs(差) < 槛["低"]:     return 0.0        # 截断
      if abs(差) > 槛["高"]:     return ±1.0        # 饱和
      return 差 / 槛["高"]                           # 线性区

  关键行为:
  - 第一帧:上轮=None → 差=0 → 返 0(跳过,不传原值)
  - 稳态后(恒常输入):差=0 → 返 0(完全 kill 稳态分量)
  - 心跳 ac(10 tick 周期):差 ∈[-0.044,+0.044] >0.015 → 线性区 ±0.055

  末梢 = d(归一后的通道)/dt = 高-pass 滤波

[模块 8:门控缩放 L256-275]

  总激活 = Σ|新激活[i]|
  if 总激活 > 当前上限:
      缩放 = 当前上限/总激活
      门控激活 = 新激活 × 缩放              # ← 等比
  else:
      门控激活 = 新激活

  热量 = Σ(门控激活²)
  活跃 = count(|门控激活| > 0.1)

  温度饱和度 = 热量 / 1.5
  功耗饱和度 = 活跃 / 15.0
  内存饱和度 = 筋树数 / (96×95 = 9120)
  压力 = max(三者)
  目标上限 = max(0.01, 6.0 × (1-pressure))
  当前上限 ← 0.9×当前上限 + 0.1×目标上限   # ← EMA,特征时间≈10.4 tick

  门控三重效应:
  (1) 积极作用:限幅保护,防止激活爆炸
  (2) 信号湮灭(洛神 v2 A8 发现):
      全脑 96×0.3 → 压后 96×0.0625 < 0.1
      功耗饱和度立刻归零,温度饱和度仍不为零
      → 两个饱和度指标给出矛盾读数
  (3) 间接抑制共火(⚠ 洛神新增 D1):
      压缩后 |激活差| 降低,更难超过 0.01/0.02 门槛
      → 高压下筋树生长停滞

[模块 9:共火 L294-336,筋生长]

  脑内共火:|激活差| > 0.01 → 连筋概率 0.15
  跨脑共火:|激活差| > 0.02 → 连筋概率 0.05
  首拍跳过(第一拍不连筋)
  每节点至多 1 新筋/拍

  跨脑 vs 脑内:(0.02>0.01,0.05<0.15)
  综合难度 = (0.02门槛 + 0.05概率) / (0.01门槛 + 0.15概率) ≈ 6×
  → 局部致密、全局稀疏

  共火触发额外源(⚠ 洛神新增 D5):
  自己点(L376-377)每 1000 tick +0.5
  这个 ±0.5 会在下一 tick 被共火检测捕获(因为 0.5 >> 0.01/0.02)
  → 回接簇附近筋密度额外提升
  → 自己点是"内稳定器"也是"共火触发器"

[附录 B:未解决的设计疑点]

  这些可能是缺陷,也可能是有意设计。没有实证,不判断对错。
