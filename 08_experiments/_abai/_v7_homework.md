【题 2: MediaPipe 468 点 → ARKit 52 权重的手算推导】
────────────────────────────────────────

核心题。不许写代码，手算。

前置知识:
  MediaPipe 输出 468 个 3D 点，嘴巴约 80 个。
  ARKit 的 mouthSmileLeft 是 0~1 的浮点数。

  任务 A:
    已知 mouthSmileLeft = 1.0 时:
      左嘴角 (lip corner) 沿 X 轴外移 +8mm
      沿 Y 轴上移 +4mm
      上唇对应点 +2mm
      
    从 MediaPipe 468 点中测得:
      当前帧左嘴角坐标 (x₀, y₀, z₀)
      中性脸左嘴角坐标 (xₙ, yₙ, zₙ)
      Δx = x₀ - xₙ
      Δy = y₀ - yₙ
      
    请推导 mouthSmileLeft 权重估算公式。
    
  任务 B:
    假设测得:
      中性脸: left_corner = (0.045, 0.620, -0.010)
      当前帧: left_corner = (0.051, 0.625, -0.008)
    手算 mouthSmileLeft 的当前值。写出完整过程，不许跳步。
    
  任务 C:
    列出此估算方法的三个误差来源。每个一句话说清楚。

        CHANNELS 3 Zrotation Xrotation Yrotation
      }

  }

  0.5 81.0 5.2 2.0 -2.8 1.6  0.1 1.1 -0.4  ...

  任务 A:
