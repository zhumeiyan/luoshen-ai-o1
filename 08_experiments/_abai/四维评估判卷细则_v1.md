汇总规则:

  四个维度都 PASS = 该能力 PASS(进入下一能力)
  一个维度 FAIL = 整体 FAIL,立案重做
  一个维度 CONDITIONAL + 三方同意 = 附条件 PASS
  架构师 D = FAIL 无论 A/B/C 如何 = 绝对 FAIL(架构师有一票否决)

洛神的权益(防止猫爪误判):

  - 洛神对 A 跑台的实测数据有异议 → 可要求"第二人独立复跑":洛神自己跑台,
    猫爪不许碰引擎。若洛神复跑与猫爪复跑一致 → A 通过。若不一致,
    架构师指定第三方数据集裁。
  - 洛神对 C 的角色互换结果有异议 → 可要求"补充陈述":洛神用 300 字以内
    解释推理分歧点,架构师决定是否采纳。
  - B 自验证没有申诉通道:B 是洛神自己跑的数据,数据不会骗人。
    洛神说"我跑出来就是这样"→ 接受。

时间线(从洛神交卷开始):

  T+0:洛神交卷
  T+1:架构师开封猫爪密封卷
  T+2:A 跑台执行(~17 分钟)
  T+3:猫爪初判(A+B+C 汇总)
  T+4:架构师独立评分(D)
  T+5:三方比对 → 出裁决
