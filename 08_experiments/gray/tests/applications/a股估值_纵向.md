# A股估值（纵向）

## 数据源 [事实]
- 源：legulegu（https://legulegu.com/api/stockdata/index-basic-pe）
- 口径：滚动市盈率（TTM）
- 窗口：近10年（2016-09-30 ~ 2026-09-16，121个月度）
- 纵向α = 当前滚动市盈率 / 近10年均值
- 落盘原始：/gray/tests/applications/_legulegu_pe/
