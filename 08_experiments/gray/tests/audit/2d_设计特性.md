## 1. J1 在 2D 下的定义

**决定**：用 `any(abs(g[i]) > 0)`（OR 逻辑），即"任一维度不归零 → J1 过"。

**理由**：
- J1 是结构判据，不是表达判据。
- g[0] 撑住 → 主体结构未塌 → J1 过。
- g[1] 受泄漏衰减至 0 → 该维不表达，但结构整体仍在。
- 改 all() 是强加"两维都必须表达"的要求，超出 J1 原意。

**实现**：`check_J()` 中 J1 行：`any(abs(g[i]) > 0 for i in range(2))`

## 2. dim1 衰减

**问题**：g[1] = 初始值 × 0.99^n，无限衰减至 ulp→0。是问题吗？

**决定**：设计特性，不处理。

**理由**：
- dim1 设计为"被动泄漏通道"（drive 仅注入 dim0，dim1 仅乘 leak）。
- 指数衰减是 leak<1 的必然数学结果。
- 加下限、加噪声都是强加约束，违反纪律。
- TRAJECTORY_MAX=100 窗口截断，实际存储值远离 ulp。

**登记为**：[判读·设计特性]，不需要修。

## 3. g[0] 符号

**问题**：正 drive 让 g[0] 更负（趋向 -30 而非 +30），符号该翻吗？

**决定**：不改。

**理由**：
- write_a 分配：a.step(+drive/2), b.step(-drive/2)，g=b-a 更负。
- 符号是人为约定，无物理意义。
- 公式层 α 用差值/比值，符号自洽。

## 公式

```
AR(1) 2D 分量方程：
  g[0][t] = leak × g[0][t-1] + drive   ← 受驱动维度
  g[1][t] = leak × g[1][t-1]            ← 泄漏维度

稳态（drive 常量）：
  g[0][∞] = drive / (1 - leak) = 100 × drive
  g[1][∞] = 0
```
