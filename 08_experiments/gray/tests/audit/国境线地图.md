# 国境线地图

状态：[判读] 灰度区

## 横轴：α ∈ [−1, +1]

```
  -1                                            0                                            +1
  ←──────────────────────────────────────────────────────────────────────────────────────────────→
  |                    |                    |                    |                    |
  电荷共轭              ↓                   下溢零果               ↑                   全同性
  (反物质域)           ↓                   (无效劳动)             ↑                   (完全复制)
                       ↓                                         ↑
                       ↓              ┌──────────────────┐        ↑
                       ↓              │  开区间 (−1,+1)  │        ↑
                       ↓              │   = 国土         │        ↑
                       ↓              │                  │        ↑
                       ↓              │  s ≠ d          │        ↑
                       ↓              │  异质才能算α    │        ↑
                       ↓              └──────────────────┘        ↑
```

## 边界点

| α 值 | 名称 | 物理意义 | 入表 |
|------|------|----------|------|
| +1   | 全同性 | s ≫ d，近似全同 | α ≈ +1 限入 |
| 0    | 下溢零果 | s = d 或零输入 | 拒收（无差异） |
| −1   | 电荷共轭 | d ≫ s，完全反向 | α ≈ −1 限入 |

## 五层

| 层级 | 内容 | 作用 |
|------|------|------|
| 机器 | 代码执行层 | 公式.py 运转，只算不定义 |
| 数学 | α 的定义与性质 | (s-d)/(s+d) 的闭式极值、边界 |
| 物理 | 量纲与观测 | 归一化.py 的真零点检查 |
| 台账 | 数据存储 | 读表.py 自动算 α，原始数值在此 |
| 协议 | 因果与时序 | 果因准入.py 未来值拒收 |

## 规则

- 开区间 (−1, +1) 是国土：只有 s ≠ d 时才可计算 α
- 边界 ±1 是极限点：物理上几乎不可达
- 0 是下溢点：s = d 则 α = 0，无有效信息，拒收
- 国土内部是连续区间，每点的 α 值唯一确定
- 灰度区不进主链，除非 α 值经审计确认

## 结论

国境线是 α 的函数，不是政治的。
公式是边界，λ 才有崩点。
