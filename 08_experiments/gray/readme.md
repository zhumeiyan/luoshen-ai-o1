# /gray/ — 灰度区

状态：**[判读]** — 不是主链，只放不定义。

## 结构

| 路径 | 用途 | 内容 |
|------|------|------|
| `tests/` | 测算结果（150行） | 按领域分的物理/化学/生物等数据 |
| `tests/audit/` | 审计记录 | 信源复核 |
| `tests/audit/链疑/` | 链上存疑 | 数据与主链有出入 |
| `tests/rejected/` | 拒收 | 信源不足或与主链冲突 |
| `tests/blind/` | 盲区 | 当前无法测算 |
| `pressure/` | 压力测试 | P1-P6，六种破坏性输入下的表现 |
| `debate/` | 攻防记录 | a≠b vs a=b 辩论、守卫行演变 |
| `feedback/` | 反馈过滤器 | 用户反馈待观察（空，待填） |

## 规则

- 只放，不定义，不压缩
- 主链只有一行：a ≠ b
- 灰度区任何内容不影响主链状态
- 用户看完后决定升级或丢弃
