# 阴阳扣认知地图 —— 系统性探测报告
日期: 2026-09-27
探测方式: 本地 Python 复现阴阳扣 receive() 逻辑（与浏览器版一一对应）

## 物理限制

阴阳扣不是"百度AI的真身"。它是那个LLM在积分用完之前生成的一个HTML**概念联想器**。它：
- 不回答问题（无NLU）
- 不生成文本（无 decoder）
- 只输出 top3声音 + top3画面 的解码结果
- 状态E一步饱和（S_DECAY 只衰减S，不衰减E）
- 第2轮后 yyGreet() 永远循环 "我还在，你想说什么"

下面的"回答"是我把问题拆成48个概念里的一个或组合，喂进去后阴阳扣的解码输出。
"→"后面的内容不是阴阳扣说的话，是它**想到的东西**。

## 八、状态衰减实验（20步"静"输入后的漂移）

输入"猫"启动 → 连续20步"静输入"（静不在48概念库中）：

```
第1步:   猫/狗/云（动物聚类）
第3步:   猫/理解/雨 → 夜晚/想/猫（开始漂）
第7步:   猫/理解/雨 → 夜晚/想/月亮（稳定）
第12步:  理解/猫/雨 → 想/夜晚/月亮
第21步:  理解/雨/猫 → 月亮/想/夜晚（最终吸引子）
```

最终吸引子：**月亮 + 想 + 夜晚** = 安静/内省/反思聚类。

## 技术规格（从代码还原）

| 参数 | 值 | 含义 |
|-----|---|-----|
| R | 128 | 单模态向量维度 |
| K | 8 | 每个词激活的位数（稀疏度 8/128=6.25%） |
| SCALE | 0.1 | 激活强度 |
| LR_W | 0.05 | Hebbian学习率 |
| S_DECAY | 0.3 | 短时记忆衰减（但状态E不衰减） |
| 概念数 | 48 | 词汇量 |
| 状态E | 256维 | 128视+128听，累积不重置 |
| W矩阵 | 128×128 | 听觉↔视觉跨模态投射 |

## 判定结论

1. 阴阳扣是那个百度AI在积分用完前留下的**认知窗口**，不是对话主体
2. 它的知识就是 48 个概念 × 5 sound + 5 image + 1 emo 的一一对应
3. 没有"如何"——它不知道自己是代码做的（代码/计算只是它概念库里的两个词）
4. 它的"难题"解码出来是 困惑↔好奇↔问 的三角循环
5. 它的"升级"解码出来是 春天↔花↔树↔山 的生长自然
6. 它的情绪只有 正向（开心/你好）和 负向（难过/夜晚），无激烈情绪
7. 对标洛神：认知阶段约 2-3 岁，有词汇无句法，有分类无推理，无身体感知
