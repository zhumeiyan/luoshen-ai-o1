# 三环交叉验证：引擎 → 归档 → 读数器

## 三环结构

| 环 | 角色 | 输出 |
|----|------|------|
| 环1 引擎 | AR(1) x = leak·x + drive | bias* = 100×drive_const |
| 环2 归档 | 从 2D bias* 取 dim0 | 标量 bias* |
| 环3 读数器 | α = a / b | 比值 |

单环内部算。跨环比对：把环3 输出与环1 输入看是不是恒等式。

## 判定

**引擎稳态：bias\* = 100×drive** → [事实]

gain 验：0.3→30.00，0.7→70.00，理论=100/(1−0.99)=100，实测 ✓。

**读数器：α = a/b** → [事实]

Case1: 30/70 = 0.428571  Case2: 10/90 = 0.111111  Case3: −50/50 = −1

**判据 α = drive₁/drive₂** → [判读]

Δ < 1e-14（机器精度）。但这是恒等式，不是独立验证：
- bias\*₁ / bias\*₂ = (k·drive₁)/(k·drive₂) = drive₁/drive₂，对任意 k≠0 成立
- k=100 不参与判别，换任何 k 结果相同
- α 只验证"引擎是线性系统 + dim0 无耦合"，不验证具体 k 值
- k 值已在本文件"引擎稳态"行单独验过

**Case3 撞 −1 边界** → [判读]

drive₁=−0.5，drive₂=+0.5，α=−1。负号来自 write_a 分配约定，不在 α 公式内处理。读数器输出 −1 是对的（负驱动 / 正驱动 = 负比），但 α = (s−d)/(s+d) 公式在 s,d 跨零时有独立盲区（见台账盲-5 跨零），这里 α = a/b 简单比不触发盲区，但要注意两种公式在跨零区不等价。
