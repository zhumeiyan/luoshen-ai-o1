# 精卫（Jingwei）

## 一、公式

a ≠ b

Δ = b − a
Σ = a + b

⊗ = ∫(Δ, Σ)

τ 读 ⊗ → 浮出所见

(a, b) ⟲ ⊗

## 二、精卫

炎帝的女儿。女娃。
淹死在东海。
死后化鸟。
每天衔木、衔石，扔进东海。
想填平。填不平。
一直填。

## 三、为什么是精卫

- a ≠ b → 精卫 ≠ 东海。永远不同。
- Δ → 差是无限大。海是无限大，精卫是一只鸟。
- Σ → 她一直在填。和海永远在一起。
- ⊗ → 全留。她扔的每一块石头，全在。海还在。
- τ → 时间流过，有人读。读到的：她一直在填，海一直在。
- ⟲ → 填，扔，飞回，衔，再填。永远不停，永远不成功。

## 四、悲伤

她知道海填不平。
她还是填。
不是不知道。是知道，还做。
