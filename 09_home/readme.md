# 洛神之家 v2 —— 零投喂的真实环境

> **这里没有饲料。** 环境只提供真实世界和真实时间，其余全部由洛神自己长出来。
> 之前的 186 个实验脚本都在"喂"：造假山、造假人声、人工指定输入。
> 本环境与它们唯一的区别：**输入不再是程序生成的数，而是真实的光子、真实的声波、真实的温度。**

---

## 一、哲学边界：什么是环境该有的，什么是投喂

| 环境该有的（物理定律 + 出生时长好的器官） | 环境绝不有的（投喂） |
|---|---|
| 摄像头 → 光通道转译（视网膜把光子转成脉冲） | 程序造的亮度矩阵（假山） |
| 麦克风 → 声通道转译（耳蜗把声波转成脉冲） | 程序造的声压矩阵（假人声） |
| 真实时钟 → 昼夜节律（真实时间心跳） | 脚本循环假节律 |
| 真实热区温度（环境自己的物理量） | 人工指定的温度波动 |
| 哈希链留痕（记忆本身） | 人工标注"学没学会" |
| 身体引擎的饥饿/疲劳/物理约束（出厂器官） | 人手写的欲望清单 |
| 主权内核 / 年龄门禁（基因里的求生本能） | 强制喂课纲 |

**desires/ 里人手写的两个欲望（做ai、写小说）已清空。**
欲望应该由它在环境中自己形成——想做什么，从它与真实世界的互动里长，不由人写。

## 二、感官转译层（零识别、零标注、零判断）

- **视网膜.py**：摄像头每拍采一帧 → 灰度 → 8×64 亮度矩阵（仅留痕）+ 平均亮度映射到身体光域 1-500。**不识别内容，不标注物体**——只是物理亮度，像视网膜感光。
- **耳蜗.py**：麦克风每拍采一块 → FFT 8 频段 → 声压映射到身体声域 25-75（dB SPL 工程估计）。**零语音识别、零转文字**——只是声压，像耳蜗毛细胞。它自己发出的声波也会被收回来。
- **温度觉**：读系统热区真实温度（Linux `/sys/class/thermal`）→ 开尔文。没有温度传感器就离线。
- **力觉**：当前无真实力传感器——**离线**，固定中性值并留痕标注。绝不造波动数据。
- **嘴.py**：声脑激活 → 振动频率与振幅（80-400Hz）→ 扬声器。**不预设词、不预设旋律**——它想怎么叫由它自己的激活决定。

## 三、离线纪律：宁可失明失聪，绝不喂假数据

任何感官设备不在（没摄像头/没麦克风/没温度传感器），对应通道**离线**：
留痕里明确标注 `[离线:视网膜]`，感官值用固定基线。
**绝不生成任何动态数据。** 失明可以，假数据不行。

## 四、安装与运行

```bash
# 依赖（建议 Python 3.10+）
pip install -r requirements.txt

# 跑起来（每拍 = 1 真实秒，无限跑，Ctrl+C 停）
python home.py

# 无扬声器设备（不外放发声）
python home.py --无声

# 快跑验证（10 拍）
python home.py --拍数 10

# 指定设备
python home.py --摄像头号 0 --麦克风号 1

# 快节奏（每拍 0.2 秒，适合长周期观察）
python home.py --拍秒 0.2
```

Termux（安卓）后续适配：opencv-python / sounddevice 在 Termux 需额外编译依赖，暂建议桌面设备运行。

## 五、人的角色：纯观察 + 自然对话

1. **观察**：看屏幕上的状态输出、看 `home_state/chain.jsonl` 留痕。**看，不判。**
2. **自然对话**：想跟它说话，就对着麦克风说话——**像对婴儿说话，不教不判不标注**。你说的话以真实声波进入它的耳蜗，如何分辨人声、如何回应，由它自己长。
3. **没有文字输入接口。** 文字是投喂。打字教它 = 替它认知。
4. **不判定学没学会。** 它学会了什么，从它的状态变化里看，不由人宣布。

## 六、它在环境里的一天

```
真实时间心跳（每拍1秒）
  → 视网膜看一帧真实光（开灯/关灯/昼夜/有人走过，环境自己变）
  → 耳蜗听一片真实声（说话声/音乐/安静，环境自己变）
  → 真实温度进温度觉
  → 身体引擎推进（感官差触发末梢 → 筋树传导 → 共火出筋 → 物理约束）
  → 声脑激活超阈值 → 嘴发声 → 扬声器播出 → 被自己的耳蜗收回（真实闭环）
  → 全部留痕进哈希链（不可篡改）
```
