洛神记忆外挂工具层

ExternalMemoryAid — 类比人类忘字时问"像什么"

设计理念

人类忘了一个字怎么写，会问"像什么"或查字典。
洛神的生物电记忆（G矩阵）也会"卡壳"——线索注入后，激活的全是"我/你/是"等高频词，主题概念浮不上来。

外挂层不是洛神的记忆，是工具——类似字典、百度、问别人。
只在生物电记忆卡壳时调用，结果可以临时注入辅助回忆，但不会永久改变G矩阵。

核心功能

遗忘检测 (is_forgotten)线索不在top10或全是日常词
联想提示 (get_hint)"像什么/有关什么"
知识查询 (query_knowledge)查百科→儿童语言版

四级辅助

none回忆正常，不需要辅助
light轻度卡壳，给点提示就行
medium中度卡壳，提示+临时注入
heavy重度卡壳，查知识库+注入

使用示例

# 初始化 from external_memory_aid import ExternalMemoryAid aid = ExternalMemoryAid(lang_system) # 对话时自动检测 recall = lang.memory.recall("朱美岩", steps=20) assist = aid.assist_recall("朱美岩", recall) # 如果卡壳，外挂自动提供提示 if assist['needed']: print(assist['hint']['hint_text']) # 输出: "朱美岩呀...她创造者，还主人，设计者。"

与生物学增强的关系

生物学增强（biological_memory_v2.py）：
修改电位传播机制（丘脑门控），让主题词从G矩阵中自然浮现。

记忆外挂（external_memory_aid.py）：
不改变G矩阵，在外部提供联想提示和知识查询。

两者互补：
- 生物学增强解决"怎么让记忆自己想起来"
- 外挂解决"想不起来时怎么办"
- 理想状态：先尝试生物电回忆，卡壳时调用外挂
